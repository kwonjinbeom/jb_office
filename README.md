`C:\JBWORKSPACE\sub_pj`

2026-08-30에 기존 OneDrive 경로의 프로젝트 자료와 생성 스크립트를 이 Git 저장소로 모두 이동했다. 이후 모든 기록과 결과물은 이 폴더를 기준으로 관리한다.

Git 동기화는 저장소 루트의 `git-sync.bat`를 실행한다. 커밋 메시지를 지정하지 않으면 실행 시각을 사용하며, 필요하면 `git-sync.bat "커밋 메시지"`처럼 실행할 수 있다.

## 최종 목표

AI와 개발 역량을 활용해 아주 작은 실행이라도 실제 인터넷에 공개하고, 실제 고객에게 판매하여 첫 수익을 만든다.

## 현재 단계

**아이디어를 사용자와 하나씩 확인하는 단계**다. 사용자의 명시적 동의 전에는 제작·게시·지원으로 넘어가지 않는다.

## 운영 원칙

1. 아이디어의 재미보다 실제 수요 증거를 우선한다.
2. 개발 가능 여부보다 판매 가능 여부를 먼저 확인한다.
3. 큰 시장보다 첫 고객에게 도달할 수 있는 작은 시장을 우선한다.
4. 무료 반응보다 결제·예약·상담·구매 흔적을 강한 증거로 본다.
5. 한 번에 하나의 초소형 실험만 실행한다.
6. 실패해도 조사 자료, 코드, 고객 언어, 유통 경로가 다음 실험에 남아야 한다.
7. 사람의 판단과 관계가 필요한 일은 사용자가 맡고, 조사·정리·제작·자동화는 Codex가 최대한 맡는다.

## 작업 문서

- `01_탐색설계.md`: 조사 범위, 증거 등급, 평가 기준
- `02_후보원장.md`: 발견한 후보와 근거
- `03_역할분담.md`: 사용자와 Codex의 책임
- `04_의사결정기록.md`: 선택·보류·탈락 사유
- `05_진행현황.md`: 지금 할 일과 완료 내역
