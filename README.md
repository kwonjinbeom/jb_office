# 인터넷 수익 실험 프로젝트

작업 공간: `C:\JBWORKSPACE\jb_office`

AI와 사용자가 여러 인터넷 시장을 탐색하고, 작은 결과물을 실제로 공개해 첫 수익까지 함께 진행하는 프로젝트다.

넓은 시장 탐색을 한 차례 마쳤고, 현재는 성격이 다른 세 초기 실험군 안에서 구체적인 문제와 형식을 검증하는 단계다. 최신 합의와 협업 방식은 `시장조사/00_현재방향.md`를 기준으로 한다.

## 현재 결론 한 줄

넓은 시장 탐색을 한 차례 마쳤다. `좁은 유료 유틸리티 + 인간 저작 Medium 글 + 원본 숏폼 IP`를 같은 깊이로 검증하고, 기존 리서치·QA·자동화는 공개 표본 이후의 빠른 현금화 축으로 보존한다.

## 핵심 문서

- `시장조사/00_현재방향.md`: 현재 목표, 조건, 탐색 범위와 협업 방식
- `시장조사/01_탐색설계.md`: 앞으로 시장을 조사하는 방법
- `시장조사/02_후보원장.md`: 발견한 후보와 시장 증거
- `시장조사/03_역할분담.md`: 작업별 역할 결정 원칙
- `시장조사/04_의사결정기록.md`: 중요한 선택과 변경 이유
- `시장조사/05_진행현황.md`: 현재 상태와 바로 다음 단계
- `시장조사/10_확장시장조사_2026-08-30.md`: 플랫폼별 최신 수익 조건·수수료·정책 조사
- `시장조사/11_통합시장지도_및_후보군.md`: 기존 의뢰 시장과 새 공개형 시장의 통합 비교
- `시장조사/12_다음작업_실행설계.md`: 다음 조사와 제작으로 넘어가는 구체적인 순서

## Git 동기화

저장소 루트의 `git-sync.bat`를 실행하면 `main` 브랜치를 pull한 뒤 모든 변경을 add, commit, push한다. 새 컴퓨터에서는 최초 한 번 GitHub 로그인을 완료하면 이후 인증 정보가 Windows 자격 증명 관리자에 저장된다.
