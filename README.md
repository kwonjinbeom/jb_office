# 인터넷 수익 실험 프로젝트

작업 공간: `C:\JBWORKSPACE\sub_pj`

AI와 사용자가 여러 인터넷 시장을 탐색하고, 작은 결과물을 실제로 공개해 첫 수익까지 함께 진행하는 프로젝트다.

현재는 아이디어 탐색 단계다. 최신 합의와 협업 방식은 `00_현재방향.md`를 기준으로 한다.

## 핵심 문서

- `00_현재방향.md`: 현재 목표, 조건, 탐색 범위와 협업 방식
- `01_탐색설계.md`: 앞으로 시장을 조사하는 방법
- `02_후보원장.md`: 발견한 후보와 시장 증거
- `03_역할분담.md`: 작업별 역할 결정 원칙
- `04_의사결정기록.md`: 중요한 선택과 변경 이유
- `05_진행현황.md`: 현재 상태와 바로 다음 단계

## Git 동기화

저장소 루트의 `git-sync.bat`를 실행하면 `main` 브랜치를 pull한 뒤 모든 변경을 add, commit, push한다. 새 컴퓨터에서는 최초 한 번 GitHub 로그인을 완료하면 이후 인증 정보가 Windows 자격 증명 관리자에 저장된다.
