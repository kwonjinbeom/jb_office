# 일일 아이디어 조사 — 2026-10-16

검색 표준 v2(2026-10-14 저장)를 따랐다. 클라우드 세션(Claude)에서 진행했다.

## 표준과 다르게 판단한 것

- **"숫자는 직접 열어 본 페이지에서만"을 지키지 못했다.** 이 클라우드 환경은 네이버·다음·구글 트렌드·유튜브·크몽·쇼핑몰 직접 접속이 막혀 있다. 그래서 모든 숫자는 **웹 검색 결과 요약(발췌)**에서 가져왔다. 링크는 해당 페이지 주소다. PC에서 다시 열어 확인할 대상이다.
- **10번(네이버 API HUB)은 '보류'인데도 넣었다.** 수요는 2027년 상반기에 몰리지만, 마감일이 고정된 '떠나는 사람' 신호라 지금 가이드 글을 먼저 써 두는 게 이득이라고 봤다.

## 7. 한계

- **직접 연 페이지가 없다.** 크몽·쇼핑몰·트렌드 화면은 모두 접속 차단(DNS 실패 또는 프록시 403). 숫자는 검색 발췌라, PC에서 원문을 열어 다시 확인해야 한다.
- 제휴 수수료는 대부분 블로그 비교 자료다. 공식 파트너 화면으로 확인된 건 마이리얼트립 '최대 7%', KKday '$200부터 지급'뿐이다.
- 검증 가설: 09의 수익 줄, 06의 금융 키워드 광고 단가, 04의 응모 분량·장르 조건, 08의 숙소 예약 전환.
