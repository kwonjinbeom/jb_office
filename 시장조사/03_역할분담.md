# 역할 분담

역할은 사람과 AI로 고정하지 않고 작업마다 속도와 결과 품질을 기준으로 정한다.

## Codex가 기본적으로 주도할 일

- 여러 시장과 매체의 사례·수요·수익 구조 조사
- 후보 분류, 비교와 실험 설계
- 글, 이미지, 영상 구성, 코드와 상품 초안 제작
- 반복 작업 자동화와 결과 측정 정리
- 사용자가 판단하기 쉬운 선택지와 근거 제시
- 작업 기록과 다음 단계 관리

## 사용자의 개입이 강점이 되는 일

- 재미, 취향, 공감, 자연스러움과 독창성 판단
- 실제 사람과 상황의 맥락 해석
- 후보 선택과 최종 공개 승인
- 본인 명의의 가입, 인증, 결제·정산과 약관 동의
- 필요한 경우 직접 촬영, 조작, 관찰 또는 창작

## 운영 방식

- Codex가 더 빠른 작업은 먼저 준비해 선택 가능한 형태로 보여준다.
- 사람의 개입이 차이를 만들면 목적과 완료 기준이 명확한 작은 작업을 요청한다.
- 사용자는 어느 단계든 직접 아이디어를 추가하거나 결과를 수정할 수 있다.
- 서로 다른 실험은 병렬 진행할 수 있지만, 큰 작업으로 확장하기 전에는 사용자에게 확인한다.
