# 진행 현황

넓은 시장 지도 작성을 마치고, 세 초기 실험군의 구체 후보를 검증하기 직전이다.

## 완료

- 작업 공간을 `C:\JBWORKSPACE\jb_office`로 정리
- `main` 전용 Git 동기화 배치파일 제작
- 새 컴퓨터에서 GitHub 최초 로그인을 처리하도록 배치파일 개선
- 빠른 직접 결제 시장의 1·2차 조사와 후보 21개 기록
- 사용자와 목표, 관심 제외 분야, 수익 방식, 협업 방식 확인
- 성급하게 제작한 특정 판매 채널용 자료 정리
- YouTube, TikTok, Facebook, Medium, 네이버, Google 검색·AdSense의 수익·AI·원본성 정책 확인
- 쿠팡·Amazon 제휴의 가입·정산 장벽 확인
- itch.io, Lemon Squeezy, Gumroad, Etsy, Notion, KDP, Adobe, Canva, Chrome·앱·에셋 스토어 조건 확인
- 기존 의뢰 시장과 공개형 콘텐츠·상품·소프트웨어 시장을 하나의 지도와 후보 C22~C35로 통합
- 초기 병렬 실험군과 다음 작업의 통과·폐기 조건 결정

## 현재 보유한 조사 자산

- 리서치, QA·현지화, 파일 자동화와 데이터 상품의 실제 구매 사례
- 계산 도구, 디지털 플래너, 게임 에셋과 콘텐츠 제작 시장의 기초 조사

기존 자료는 빠른 의뢰형 시장의 구매 증거로 보존한다. 새 확장 자료는 플랫폼 공식 정책과 수수료를 더했고, 둘을 합친 현재 판단은 `11_통합시장지도_및_후보군.md`에 있다.
