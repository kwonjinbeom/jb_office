# 블로그·카페 포스트 자동화 — 접근 설계

확인일: 2026-10-14. 목적은 글을 꾸준히 만드는 방법과 수익 연결을 비교하는 것. 아직 채널 개설·외부 게시·자동화 개발은 하지 않았다.

## 1. 조사 범위와 근거 수준

Google 검색 문서·AdSense, 다음 검색, 네이버 도움말, Ahrefs, WordPress 개발자 사이트, Ghost 리소스 사이트는 이 환경에서 직접 접근이 403으로 차단됐다. 대신 아래의 **공식 GitHub 문서·API 자료·공개 편집 지침을 실제로 읽었다.**

- 직접 확인: 편집·검토 흐름, 글 형식별 템플릿, 게시·예약 API, 자동화 구성 요소, 측정 도구, Ghost 회원·뉴스레터 기능.
- 기존 조사 재사용: 광고·제휴를 통한 블로그 수익 구조. `10_확장시장조사_2026-08-30.md`의 정보이며 이번에 최신 조건을 재확인한 것은 아니다.
- 미확인: 현재 국내 플랫폼의 게시 API·자동 조작 허용 범위, 광고 승인·수수료·정산 조건, 실제 개인 블로거의 순수익과 성공률.
- 아래 전략·예시·실험 수치는 **우리의 제안**이다. 도구 기능이나 타인의 매출 표현을 수익 증거로 취급하지 않는다.
- 자료 접근 여부로 플랫폼 순위를 정하지 않는다. 합의된 트렌드 출처 6곳의 동등한 순위도 유지한다.

## 3. 수익화는 글의 목적에 붙인다

| 경로 | 독자가 얻어야 하는 것 | 연결 방식 | 먼저 확인할 것 |
|---|---|---|---|
| 광고 | 반복해서 찾는 설명·해결·자료 | 방문과 페이지 이용 → 광고 | 플랫폼·프로그램 가입, 승인, 지급 조건. 초기 수익 예상은 보류 |
| 제휴 | 무엇을 사거나 선택할지 판단 | 비교·사용 조건 → 공개 표시가 있는 제휴 링크 | 제휴 등록·해당 게시처 허용 범위·표시 기준·유효 구매 |
| 자체 상품·도구 | 글보다 바로 쓸 결과물 | 설명·사례 → 파일·템플릿·도구 | 글을 읽는 사람이 결과물을 실제로 원하는지 |
| 유료 자료·구독 | 계속 갱신되는 정보·독자적인 해석 | 무료 글 → 유료 갱신 자료·뉴스레터 | 재방문·지속 가치와 결제·정산 가능성 |
| 협찬·작업 요청 | 특정 독자에게 도달하거나 실력을 확인 | 포트폴리오·독자층 → 계약 | 초기 주력이 아니라 공개 결과와 반응 뒤 검토 |

카페는 **내가 운영하는 카페**와 **남의 카페에 올리는 글**을 구분해야 한다. 참여자의 게시글 조회가 곧 개인 광고 수입이라는 가정은 하지 않는다. 질문·답변·사례 공유를 통해 독자 반응을 보고, 허용된 게시판과 방식에서만 수익 연결을 검토한다. 이는 운영 제안이며 네이버·다음 카페의 최신 약관을 확인했다는 뜻은 아니다.

## 4. 소재는 다섯 부류로 탐색

- **해결:** 사람들이 자주 막히는 한 단계, 오류, 절차. 도구·IT뿐 아니라 취미·생활에도 적용.
- **선택:** A/B, 가격·조건, 누구에게 무엇이 맞는가. 제휴나 자체 상품으로 연결할 여지가 있다.
- **경험:** 직접 해본 과정·실패·변화. 테스트하지 않은 내용을 실제 경험처럼 쓰지 않는다.
- **해석:** 업데이트·새 소식이 내 독자에게 무엇을 바꾸는가. 단순 요약보다 적용 조건을 붙인다.
- **참여:** 취향·상황·사례를 비교하고 구체적인 질문을 남긴다. 카페의 실제 댓글이 후속 소재가 된다.

많이 검색되는 단어와 구매 의도가 있는 질문은 다르다. 검색량만으로 주제를 선택하지 말고, 실제 질문·불편·유료 대안·독자가 선택할 행동을 함께 본다. 사용자 관심사인 게임·애니메이션·음악, 컴퓨터 작업, 생활형 관심사 모두 열어 두며 이번에 한 분야로 확정하지 않는다.

## 5. 글 형식별 기본 틀

| 형식 | 뼈대 | 채워야 하는 원본 | 수익과 연결할 때 |
|---|---|---|---|
| 해결형 | 상황 → 답 먼저 → 단계 → 막히는 조건 → 요약 | 재현한 절차·화면·오류 조건 | 관련 도구·체크리스트 |
| 비교형 | 대상 독자 → 비교 기준 → 표 → 조건별 선택 → 단점 | 확인일이 있는 가격·기능·사용 조건 | 맞는 독자에게만 제휴·상품 |
| 경험형 | 시작 상황 → 실제 과정 → 결과 → 실패·주의 → 다음 실험 | 실제 기록·수치·사진 또는 작업 결과 | 사용한 자료·도구·후속 결과물 |
| 큐레이션형 | 이번 주제 → 선정 기준 → 항목별 한 줄 해석·링크 → 활용법 | 원문·확인일·선정 이유 | 반복 갱신 자료·뉴스레터 |
| 카페 대화형 | 구체적 상황 → 짧은 정보·경험 → 내 판단 → 답하기 쉬운 질문 | 해당 커뮤니티의 관심사·규칙 | 우선 반응 확인, 홍보 가능 여부 별도 |

제목도 구체적으로 쓴다. 예: `[상황]에서 [문제] 해결하는 방법`, `[A]와 [B], [조건]이면 무엇이 맞을까`, `[직접 한 일]에서 막힌 점과 바꾼 방법`. 이는 작성용 예시이며 검색 순위 공식은 아니다.

**템플릿의 공통 입력은 8개면 충분하다:** 독자 / 질문 / 결론 한 줄 / 근거 / 직접 확인한 것 / 말투 / 예외·단점 / 다음 행동. 글 길이는 답해야 할 질문에 맞추고, 특정 글자 수나 키워드 반복 횟수를 통과 공식으로 두지 않는다.

같은 소재를 재사용하더라도 블로그는 검색 질문에 완결된 답을 주고, 카페는 해당 모임의 맥락과 질문에 맞춰 다시 구성한다. 제목만 바꾼 일괄 배포와는 제작 목적이 다르다.

## 6. 자동화할 것과 사람이 결정할 것

제안 흐름: `소재·출처 → 글 카드 → 형식 선택 → 초안 → 사실·경험 확인 → 채널별 편집 → 게시·예약 → 반응 기록 → 기존 글 갱신`.

| 단계 | 자동화 후보 | 사람이 맡을 핵심 |
|---|---|---|
| 소재 | 허용된 RSS·공식 공지 수집, 날짜·원문 보관, 중복 표시 | 우리 독자의 실제 문제인지 |
| 작성 | 개요·초안·표·제목 후보·게시처별 변형 | 실제 경험·취향·핵심 판단 |
| 검수 | 링크·빈 항목·확인일·주장별 출처 체크 | 가격·정책·인용·사진·주장의 실제 확인 |
| 게시 | 확인된 공식 API로 초안 등록, 승인된 원고 예약 | 채널 규칙·이미지·최종 원고 |
| 유지 | 게시 URL·반응 수집, 오래된 글 갱신 알림 | 무엇을 더 만들고 줄일지 |

WordPress·Blogger·Ghost는 이번에 게시 API를 확인했다. 국내 블로그·카페는 이번 조사에서 현재 API·허용 범위를 확인하지 못했으므로, 우선 **게시용 원고 준비까지**를 자동화 대상으로 둔다. Claude의 브라우저 접근 가능 여부와 해당 사이트의 자동 게시 허용 여부는 별개다.

n8n은 기존 노드와 예제 목록을 출발점으로 삼을 수 있다. 범용 자동화 서비스를 먼저 개발할 필요는 없다. 처음에는 현 작업서버와 Markdown 원고로 제작 흐름을 확인하고, 반복되어 귀찮은 구간부터 연결한다. 이번에는 도구 설치·계정 연결·외부 게시를 실행하지 않았다.

## 7. 꾸준히 운영하는 방법과 작은 검증

- 한 독자층 안에 오래 읽힐 글, 비교·선택 글, 소식·대화 글을 구분해 쌓는다.
- 글 한 편을 쓸 때 관련 글과 후속 질문도 기록해 다음 소재를 확보한다.
- 작성일만 보지 말고 사실 확인일·가격 변경·깨진 링크를 갱신한다.
- 소재 찾기와 원고 작성, 검토를 묶어서 작업하면 매번 전환하는 부담을 줄일 수 있다.
- 글의 진입은 질문·답·비교 기준으로 시작한다. 범용 인사말과 같은 서론을 반복할 필요는 없다.
- 평가할 것은 글 수보다 **유입 → 읽기·질문 → 클릭·사용 → 유효 구매**의 연결이다. 광고 클릭 유도는 하지 않는다.

**첫 검증 제안:** 독자층 1개, 주제 2개, 템플릿 2개를 고르고 4주간 8편 정도를 제작·검토한다. 수량과 기간은 운영 부담을 확인하기 위한 예시이며 매출 목표나 검색 평가 기준이 아니다. 초기에는 검토 시간·수정량·구체적인 질문·다음 글 소재가 생기는지 보고, 검색·수익은 더 긴 기간 관찰한다.

기록은 `게시 URL / 유입·검색 질문 / 반응·수익 행동 / 제작·수정 부담 / 다음 개선 한 줄`로 제한한다. 모든 글의 모든 숫자를 억지로 관리하지 않는다. 실제 수익이 나면 비용·환불·무효 전환까지 포함해 순수익을 따로 본다.

## 8. 현재 판단과 다음 논의

추천은 **카테고리별 반자동 제작**이다. 글의 독자·형식을 먼저 정하고, AI가 자료·초안·변형을 맡고 사람이 사실과 핵심 판단을 확인한다. 유입 목적에 맞는 수익 경로를 붙이고, 검증한 채널부터 게시 자동화를 확대한다.

아직 정할 것: ① 첫 독자·카테고리 ② 첫 게시처와 카페 운영/참여 방식 ③ 우선 시험할 글 형식 2개 ④ 광고·제휴·자체 상품 중 첫 연결 ⑤ 브라우저로 보완할 국내 정책·사례.
