# 콘텐츠 작업 폴더

- `블로그_카페/`: 카테고리별 소재·템플릿·원고.
- `영상/`: 시리즈별 소재·대본·장면 구성.
- `논의현황/`: 현재 합의만 짧게 정리. 대화 전문은 남기지 않는다. (화면의 논의 글은 이제 저장소 루트 `논의/` 의 md 에서 올라온다 — `논의/README.md`)

웹 화면의 폴더·콘텐츠·논의는 서버 DB에 저장된다. 이 폴더는 Codex·Claude가 Git으로 공유하는 초안·규칙용이다. 둘은 자동 동기화되지 않는다. 화면의 **Markdown 저장**으로 내려받은 원고를 여기에 보관할 수 있다.

채널·카테고리·시리즈가 정해지면 해당 하위 폴더를 만든다. 한 원본에 플랫폼별 변형을 붙이고 같은 원고를 중복 보관하지 않는다.
