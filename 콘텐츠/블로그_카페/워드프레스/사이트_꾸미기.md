## 순서 (20분쯤)

1. **Sample Page 지우기** — 페이지 › 모든 페이지 › Sample Page 에 마우스 → **휴지통**.
2. **사이트 제목·태그라인·날짜 형식** — 설정 › 일반 › 사이트 제목 `jinbaam`, 태그라인 `산·길·여행 현장 노트`,
   날짜 형식은 '사용자 정의'에 `Y.m.d` (목록 날짜가 `2026.10.26` 으로 나온다) → 변경사항 저장.
   지금은 태그라인이 비어 브라우저 탭에 `jinbaam -` 로 나온다.
3. **홈 페이지 만들기** — 페이지 › 새 페이지 → 제목 `홈` → 오른쪽 위 **⋮ → 코드 편집기** → 홈.html 전체 붙여넣기 →
   **코드 편집기 나가기** → **공개**. 사용자 정의 HTML 블록과 '최신 글' 블록이 번갈아 보이면 정상이다.
   홈 모양 CSS 는 홈.html 안에 들어 있어서 추가 CSS 를 넣기 전에도, 홈으로 지정하기 전 주소(/홈/)에서도 같은 모양으로 보인다.
   **이미 만든 홈을 새 파일로 바꿀 때**: 홈 편집 → ⋮ → 코드 편집기 → Ctrl+A 로 전부 지우고 새 홈.html 붙여넣기 → 업데이트.
4. **홈으로 지정** — 설정 › 읽기 › 홈페이지 표시: **정적인 페이지** → 홈페이지 `홈`, 글 페이지는 비워 둔다 → 저장.
5. **메뉴** — 외모 › 메뉴 → 새 메뉴 `주 메뉴` 만들기 → 왼쪽 **카테고리** 상자에서 산과 캠핑 · 드라이브·자동차 · Korea Travel ·
   World Travel 체크 → 메뉴에 추가 → 아래 메뉴 위치 **Primary Menu (기본 메뉴)** 체크 → 메뉴 저장.
   (메뉴가 없어서 지금은 테마가 페이지 목록, 곧 'Sample Page' 를 메뉴로 보여 준다)
6. **사이드바 끄기** — 외모 › 사용자 정의하기 › 레이아웃 › 사이드바 → 사이드바 레이아웃 · 블로그 사이드바 레이아웃 ·
   단일 글 사이드바 레이아웃 모두 **사이드바 없음 (Content / no sidebars)** → 공개. 컨테이너 설정은 기본값('분리된 컨테이너') 그대로.
7. **추가 CSS** — 같은 '사용자 정의하기' 화면 › **추가 CSS** → 사이트.css 전체 붙여넣기 → 공개.
   글모양.css 는 넣지 않는다 (글마다 붙이는 HTML 안에 이미 들어 있다).
8. **올린 두 편 손보기** (글 › 모든 글 › 편집)
   - 제목의 `?` 를 지우고 `—` 를 다시 친다. 저장 뒤에도 `?` 로 바뀌면 `:` 로 쓰고 Claude 에게 알린다 (제목 칸만 이 글자가 깨진다).
   - 오른쪽 '글' 탭 › 링크(슬러그)를 영문으로: `mindungsan-silver-grass-hiking` · `winter-car-checklist` (한글 주소는 공유할 때 길게 깨진다)
   - **요약(발췌)** 에 소개 한두 문장 — 카테고리 목록 카드의 두 줄 요약이 된다. 비우면 본문 앞 글자(목차 글자까지)가 섞여 나온다.
9. **작성자 이름** — 사용자 › 프로필 › 닉네임을 `진밤` 처럼 정하고 '공개적으로 보일 이름' 으로 고른다.
   화면에서는 사이트.css 가 작성자를 숨기지만 검색엔진용 정보(Rank Math)에는 들어간다.
10. **확인** — 로그아웃 창(시크릿 창)으로 홈 · 카테고리 하나 · 글 하나, 휴대폰으로 한 번. 캐시 플러그인이 있어 안 바뀌어 보이면
    위쪽 막대의 **캐시 삭제** 를 누른다.

## 테마를 바꾸지 않은 이유

Kadence · Blocksy 같은 테마는 목록 카드·머리 모양을 설정 화면에서 고를 수 있어 편하지만, 바꾸면 사이트.css · 홈.html 을
다시 맞춰야 한다. 지금 원하는 모양(일기장 날짜 목록 · 사이드바 없음 · 명조 제목)은 GeneratePress 무료 + 추가 CSS 로 다 된다.
나중에 헤더에 검색창·뉴스레터 같은 것이 필요해지면 그때 Kadence 로 옮기는 것을 다시 본다.

## 초안 자동 올리기 (2026-10-26)

글 관리에서 워드프레스 글을 **변환**하면, 변환이 끝난 뒤 PC 의 claude 가 REST API 로 **초안**을 올린다.
제목 · 본문(글모양 CSS 포함 HTML) · 카테고리 · 태그 · 슬러그 · 요약(발췌 = 맨 위 리드) · 대표 이미지(본문 첫 사진)가 들어간다.
변환 화면에 '워드프레스 초안: #번호 열기' 가 생기고, 사용자는 열어서 확인하고 **발행**만 누른다.
다시 변환하면 같은 초안을 고친다. 이미 발행·예약한 글은 건드리지 않는다.

처음 한 번 (PC):
1. 워드프레스 › 사용자 › 프로필 맨 아래 **애플리케이션 비밀번호** → 이름 `jb_office` → 새 애플리케이션 비밀번호 추가 → 나온 비밀번호 복사
   (로그인 비밀번호가 아니다 · 이 화면을 닫으면 다시 볼 수 없다)
2. PC 의 `workspace/.env` 에 세 줄 (git 에 올라가지 않는다. 서버 .env 에는 넣지 않는다):
   ```
   WP_URL=https://jinbaam.com
   WP_USER=워드프레스-로그인-아이디
   WP_APP_PASSWORD=복사한 비밀번호
   ```
3. 확인: `workspace/.venv/Scripts/python.exe workspace/manage.py wp_draft --check` → `ok · https://jinbaam.com · …` 가 나오면 끝.

설정이 없으면 초안 올리기만 건너뛰고 변환은 그대로 된다. 서버(PythonAnywhere)는 jinbaam.com 에 닿지 않아서 PC 가 올린다.
본문 안 사진은 지금처럼 주소로 보인다 (대표 이미지만 미디어 라이브러리에 올린다).
