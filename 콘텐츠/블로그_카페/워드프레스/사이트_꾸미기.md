## 순서 (20분쯤)

1. **Sample Page 지우기** — 페이지 › 모든 페이지 › Sample Page 에 마우스 → **휴지통**.
2. **사이트 제목·태그라인·날짜 형식** — 설정 › 일반 › 사이트 제목 `jinbaam`, 태그라인 `산·길·여행 현장 노트`,
   날짜 형식은 '사용자 정의'에 `Y.m.d` (목록 날짜가 `2026.10.26` 으로 나온다) → 변경사항 저장.
   지금은 태그라인이 비어 브라우저 탭에 `jinbaam -` 로 나온다.
3. **홈 페이지 만들기** — 페이지 › 새 페이지 → 제목 `홈` → 오른쪽 위 **⋮ → 코드 편집기** → 홈.html 전체 붙여넣기 →

## 초안 자동 올리기 (2026-10-26)

글 관리에서 워드프레스 글을 **변환**하면, 변환이 끝난 뒤 PC 의 claude 가 REST API 로 **초안**을 올린다.
제목 · 본문(글모양 CSS 포함 HTML) · 카테고리 · 태그 · 슬러그 · 요약(발췌 = 맨 위 리드) · 대표 이미지(본문 첫 사진)가 들어간다.
변환 화면에 '워드프레스 초안: #번호 열기' 가 생기고, 사용자는 열어서 확인하고 **발행**만 누른다.
다시 변환하면 같은 초안을 고친다. 이미 발행·예약한 글은 건드리지 않는다.

처음 한 번 (PC):
1. 워드프레스 › 사용자 › 프로필 맨 아래 **애플리케이션 비밀번호** → 이름 `jb_office` → 새 애플리케이션 비밀번호 추가 → 나온 비밀번호 복사
   (로그인 비밀번호가 아니다 · 이 화면을 닫으면 다시 볼 수 없다)
2. PC 의 `workspace/.env` 에 세 줄 (git 에 올라가지 않는다. 서버 .env 에는 넣지 않는다):
   ```
   WP_URL=https://jinbaam.com
   WP_USER=워드프레스-로그인-아이디
   WP_APP_PASSWORD=복사한 비밀번호
   ```
3. 확인: `workspace/.venv/Scripts/python.exe workspace/manage.py wp_draft --check` → `ok · https://jinbaam.com · …` 가 나오면 끝.

설정이 없으면 초안 올리기만 건너뛰고 변환은 그대로 된다. 서버(PythonAnywhere)는 jinbaam.com 에 닿지 않아서 PC 가 올린다.
본문 안 사진은 지금처럼 주소로 보인다 (대표 이미지만 미디어 라이브러리에 올린다).

### 초안 자동 올리기가 401 로 막힐 때: .htaccess 네 줄 (2026-10-27 확인)

`wp_draft --check` 가 `401 rest_not_logged_in` 이면 Cafe24 서버가 인증 헤더(Authorization)를 워드프레스에 넘기지 않는 것이다
(틀린 아이디로 보내도 같은 답이 오는 것으로 확인. XML-RPC 는 Cafe24 가 406 으로 막는다).
Cafe24 호스팅 관리의 **웹FTP**(또는 FTP 프로그램)로 워드프레스 폴더(보통 `www`)의 `.htaccess` 를 열어 **맨 위**(`# BEGIN WordPress` 보다 위)에 붙인다:

```
# BEGIN jb_office REST 인증
SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]
</IfModule>
# END jb_office REST 인증
```

저장 뒤 `wp_draft --check` 를 다시 돌린다. 사이트가 열리지 않으면 이 여덟 줄만 지우면 원래대로 돌아간다.

   | 개인정보처리방침 · Privacy Policy | `privacy-policy` | 페이지_개인정보처리방침.html |
3. 설정 › 개인정보 보호 → 개인정보처리방침 페이지로 방금 만든 페이지를 고른다.
4. 외모 › 메뉴 → 페이지 상자에서 About 을 메뉴 끝에 추가 → 저장. 문의·개인정보처리방침은 홈 맨 아래와 About 페이지에서 이어진다
   (홈 맨 아래 링크는 새 홈.html 에 들어 있다 — 홈을 다시 붙여 넣는다).
5. 개인정보처리방침은 일반적인 개인 블로그 기준으로 쓴 초안이다. 광고·통계 도구를 붙이면 그 내용과 시행일을 고친다.

## 검색 등록 (2026-10-27)

**구글 서치 콘솔**
1. https://search.google.com/search-console → 속성 추가 → **URL 접두어** `https://jinbaam.com/` → 확인 방법 **HTML 태그** → `content="…"` 안의 값만 복사.
2. 워드프레스 › Rank Math › 일반 설정 › **웹마스터 도구** › Google Search Console 칸에 붙여넣기 → 변경 사항 저장 → 서치 콘솔에서 **확인**.
3. 서치 콘솔 › Sitemaps → `sitemap_index.xml` 제출.
4. 등록하면 jb_office 의 검색 성과 받기(`manage.py search_perf`)가 jinbaam.com 도 저절로 읽는다 (서치 콘솔에 있는 사이트를 다 읽는다).

**네이버 서치어드바이저** (한국어 글: 산과 캠핑 · 드라이브·자동차)
1. https://searchadvisor.naver.com → 웹마스터 도구 → 사이트 등록 `https://jinbaam.com`.
2. 소유 확인은 **HTML 파일 업로드**: 네이버가 주는 파일을 내려받아 위 .htaccess 와 같은 폴더(`www`)에 웹FTP로 올린다 → 확인.
   (Rank Math 무료에는 네이버 칸이 없다. 웹FTP 를 여는 김에 .htaccess 와 같이 한다)
3. 요청 › **사이트맵 제출**: `https://jinbaam.com/post-sitemap.xml` · `https://jinbaam.com/page-sitemap.xml` (하나씩).

5. 검증 › 웹 페이지 최적화로 홈을 한 번 검사해 본다.
