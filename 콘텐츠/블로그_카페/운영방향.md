# 블로그·카페

- 포스팅 자동화의 목표는 **AI가 이미지·말투·전개까지 갖춘 완성 원고를 만들고, 사용자는 조금 다듬어 게시하는 것**이다. 글쓰기 교육·단계별 수동 작성 안내가 아니다.
- 최신 요구 기준: [포스팅 자동화 요구사항](포스팅자동화/00_요구사항.md).
- 구조: 채널 → 카테고리 → 세부 주제 → 게시글.
- 카테고리 설정: 독자 / 목적 / 말투 / 기본 구성 / 출처 기준.
- 글 흐름: 소재 → 기획 → 초안 → 검토 → 게시 준비 → 게시 완료.
- 게시 기록: 게시처 / URL / 날짜 / 반응·개선 한 줄.
- 첫 채널·카테고리와 게시 주기는 아직 미정.
