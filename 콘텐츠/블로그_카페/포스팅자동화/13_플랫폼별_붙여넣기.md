# 플랫폼별 붙여넣기 — 사이트별 템플릿 변환의 기준

조사: 2026-10-16 (한국시간), Claude (플랫폼마다 조사 1~2건, 아래 부록이 원문). 등급: [공식] 회사 문서·공지·공식 저장소 코드 · [관찰] 공식 공지 페이지의 실제 저장 HTML 을 받아 확인 · [2차] · [경험담] · [추정].

**배경 (사용자 2026-10-16).** 글은 편집기 없이 쓴다. 모든 글은 한 분류로 정리하고, 사이트별 템플릿 변환이 마지막에 그 사이트·플랫폼에 맞춘다. 사용자는 변환본을 **통째로 복사해 그 사이트 글쓰기 화면에 붙이고** 거기서 마무리한다. 그래서 변환본의 꼴과 복사 방식을 플랫폼마다 정했다.

## 5. 변환 규칙 (도구에 넣은 것)

- **변환본은 늘 마크다운**: `##` 부터 소제목, `| 표 |`, 사진은 `[사진: 설명]` 한 줄, 글자색·크기·글꼴 꾸밈 없음. 태그는 쉼표 한 줄로 따로. 복사할 때 도구가 플랫폼에 맞게 바꾼다 (`apps/site_templates/paste.py`).
  - 티스토리·블로거: 꾸밈 없는 HTML (`markdown` 변환만, 인라인 style 없음)
  - 네이버: 네이버 글쓰기 렌더러의 서식 HTML (인라인 style)
  - 워드프레스: 마크다운 그대로
- **플랫폼 포맷 규칙**은 사이트별 템플릿 화면의 '붙여넣기 포맷'(DB)에 넣었다 (migration `site_templates.0003`). 요청문에 그대로 들어가 Claude 가 변환할 때 지킨다. 화면에서 고치면 그것이 원본이다.

## 6. 직접 한 번 붙여 봐야 확정되는 것

로그인한 에디터에서 시험하지 않았다 (자동 게시·로그인은 하지 않는 원칙). 첫 변환 글을 붙일 때 아래를 보면 된다.
- 티스토리: HTML 모드에 붙인 blockquote·hr·pre 가 고유 인용·구분선·코드블럭으로 보이는지, 기울임·취소선
- 네이버: 기울임·밑줄·취소선·배경색, 일반 문단 가운데 정렬, `[사진: …]` 줄이 어떻게 들어가는지, 이모지 저장
- 블로거: 이모지, style·class 유지, 검색 설명 글자 수
- 워드프레스: 쓰는 곳이 WP.com 인지 설치형인지 (요금제에 따라 HTML 허용 범위가 다르다)

## 6. 권장 붙여넣기 방식과 붙인 뒤 손볼 것

| 구분 | 권장 | 등급 |
|---|---|---|
| 기본 방식 | **HTML 모드에 정리된 HTML을 붙인 뒤 기본모드로 돌아와 확인한다.** 서식 있는 텍스트를 기본모드에 붙이면 원본의 color, text-align, data-* 같은 군더더기와 `&nbsp;`가 그대로 박힌다([공식-관찰]·[경험담]). HTML 모드에 우리가 만든 깨끗한 태그를 넣는 편이 결과를 통제하기 쉽다. | [추정](근거 있음) |
| 변환 규칙 1 | 소제목은 h2(제목1), h3(제목2), h4(제목3)만 쓴다. h1, h5, h6은 쓰지 않는다. | [공식-관찰]+[2차] 기반 |
| 변환 규칙 2 | 문단은 `<p data-ke-size="size16">`, 목록은 `data-ke-list-type`을 붙여 에디터 출력 형식에 맞춘다. 맞추지 않아도 되는지는 확인 못 함. | [추정] |
| 변환 규칙 3 | inline `style`(색, 배경, 글꼴), `class`, 외부 data-* 속성을 넣지 않는다. 에디터가 보존하든 지우든 결과가 지저분하거나 예측하기 어렵다. | [추정] |
| 변환 규칙 4 | `&nbsp;`를 넣지 않는다. 일반 공백을 쓴다. | [경험담] 기반 |
| 변환 규칙 5 | 이모지는 유니코드로만 쓴다. 티스토리 이모티콘은 종료됐다. | [공식] |
| 변환 규칙 6 | 이미지는 원고에 넣지 않고 "[이미지: 설명]" 자리표시로 둔다. 사람이 에디터에서 직접 업로드해야 대표 이미지(썸네일)가 잡힌다. | [공식](FAQ 39670) |
| 변환 규칙 7 | 링크 카드나 유튜브는 URL만 한 줄로 따로 둔다. 사람이 기본모드에서 그 줄에 URL을 붙여넣고 Enter를 치면 자동으로 변환된다. | [공식](2478, 2481, 2690) |
| 변환 규칙 8 | 표는 단순한 `<table>`(thead/tbody, 병합 없음)로 둔다. 엑셀에서 붙이면 텍스트만 들어오므로 원고에서 이미 HTML 표여야 한다. | [경험담] |
| 변환 규칙 9 | 코드는 `<pre><code>`로 넣는다. 코드블럭 언어 지정과 하이라이트는 사람이 툴바 코드블럭으로 다시 넣는 것을 권한다(붙여넣기로 codeblock이 되는지는 확인 못 함). | [공식]+확인 못 함 |
| 변환 규칙 10 | 접은글, 인용 스타일, 구분선 스타일은 원고에서 만들지 않는다. "[접은글 시작/끝]" 같은 표시만 두고 사람이 에디터 버튼으로 만든다. HTML 구조를 직접 넣는 방법은 [추정] 단계다. | [추정] |
| 붙인 뒤 사람이 할 일 | ① 기본모드 미리보기로 소제목, 목록, 표를 확인한다. ② 이미지를 업로드하고 대표 이미지를 지정한다. ③ 링크 카드와 유튜브 URL을 Enter로 변환한다. ④ 필요하면 인용, 구분선 스타일과 접은글을 버튼으로 적용한다. ⑤ 코드블럭 언어를 지정한다. ⑥ 태그, 카테고리, 공개 설정을 고른다(발행 화면). ⑦ 기본과 HTML 모드를 여러 번 오가지 않는다(`&nbsp;`가 쌓인다는 [경험담]). ⑧ 모바일 앱에서는 접은글과 html 블럭을 편집할 수 없으니 PC에서 마무리한다([공식]). | 혼합 |

## 6. 권장 붙여넣기 방식과 붙인 뒤 손볼 것

### 변환 규칙 (근거 등급 표시)
1. **인라인 style 만 쓴다.** class·`<style>` 은 버려진다 [자체 실측].
2. **본문 단락에는 글꼴·크기·줄간격을 싣지 않는다** → 에디터 기본(나눔고딕 15 / 180%)을 따른다 [경험담]. 꼭 지정하면 글꼴은 한글 이름(`나눔고딕`·`나눔명조`·`나눔바른고딕`·`나눔스퀘어`·`마루부리`), 크기는 에디터 단계값(15·16·19·24…) [자체 실측 + 추정].
3. **소제목은 `h2`+굵게+24px(또는 19px)** 로 보내 크기라도 남긴다. 컴포넌트 지정은 사람이 한다 [자체 실측 + 추정].
4. 강조색은 `<strong><span style="color:…">` 처럼 **span 에 색**을 둔다 [경험담].
5. **표는 단순 `table/tr/td`**, 머리줄은 `td`+굵게+배경색 [경험담 + 추정]. 셀 병합·중첩 표는 쓰지 않는다 [추정].
6. border-radius·flex·grid·position·여러 열 배치·빈 span 장식은 쓰지 않는다 [경험담].
7. 문단 간격이 필요하면 빈 문단 하나 [경험담].
8. 사진·지도·링크 카드·글감·스티커는 **`[사진1] 설명` 같은 글 자리 표시**로 둔다. 점선 `div` 상자는 1칸 표로 바뀌니 상자 대신 **한 줄 글**이 지우기 쉽다 [자체 실측 + 추정].
9. 본문에 `#단어` 를 쓰지 않는다 (태그로 등록될 수 있음). 태그는 태그 칸용으로 따로 준다, 30개 이하 [2차].
10. 이모지·특수문자는 미확인이므로 **적게**, 제목에는 넣지 않는다 [2차 + 추정].

## 6. 권장 붙여넣기 방식과 붙인 뒤 손볼 것

**권장: HTML 보기에 "깨끗한 HTML" 붙여넣기** — [추정] (근거: 본문이 HTML 로 저장됨[공식 D1], 작성 보기 붙여넣기는 숨은 서식이 따라와 깨진다는 2차 S6·S7, 표·코드는 HTML 보기가 일반적 S8·S9)

변환 규칙 제안 [추정]:
- 쓰는 태그: `h2`(Heading)·`h3`(Subheading)·`p`·`strong`·`em`·`u`·`s`·`a href`·`ul/ol/li`·`blockquote`·`table/tr/th/td`·`pre/code`·`img src="https://…" alt`·`<!-- more -->`
- 쓰지 않는 것: `h1`(제목과 겹침), `<html>/<head>/<body>`, `<script>`, 인라인 `style`·`class`(유지 여부 확인 못 함·테마와 충돌), `http://` 주소
- 여러 줄 `<script>` 금지 (편집기가 줄바꿈 태그를 끼움 S13)
- 이모지는 넣어도 되나 기기마다 모양 다름 — 핵심 정보는 글자로

붙인 뒤 손볼 것:
1. 작성 보기로 한 번 넘겨 표·목록·제목이 그대로인지 확인 (전환 시 변형 여부는 확인 못 함 → 눈으로 확인)
2. 라벨: 20개 이하, 쉼표 구분, 합계 200자 이하
3. 검색 설명: 150자 이내 (설정에서 켜져 있어야 칸이 보임)
4. 맞춤 퍼머링크: 영문·숫자·하이픈 (게시 전에 정하기)
5. 점프 나누기 위치 (`<!-- more -->` 또는 버튼)
6. 첫 이미지 = 목록 썸네일이 되므로 맨 위 이미지 확인, 외부 이미지는 https
7. 미리보기로 최종 확인 후 게시

## 확인 못 한 것 (요약)
- HTML 보기 허용·제거 태그 공식 목록, `<style>`·`style`·`class` 유지 여부
- 작성 보기 ↔ HTML 보기 전환 시 현재 편집기의 변형
- 구분선·코드·글 정렬 도구 유무, 이미지 "URL로 넣기" 현재 유무
- 유니코드 이모지 저장 문제 유무, 제목 하드 제한, 본문 크기 공식 제한
- 위치(location) 입력이 현재 편집기에 남아 있는지

| 대표 이미지 | 사이드바 "Set featured image" → **미디어 라이브러리**에서 선택/업로드. 외부 URL 입력 칸 없음 | 사이드바 또는 이미지 블록 ⋮ → "Set as featured image". 외부 URL 가능 여부 문서 없음 | [공식] 사이드바 문서 · [공식] https://wordpress.com/support/featured-images/ |
| 붙여넣은 외부 이미지를 대표 이미지로 | 먼저 "Upload to Media Library" 로 첨부물이 돼야 함 | — | [추정] 대표 이미지는 첨부물 ID(_thumbnail_id) 기반 |
| 슬러그 | 사이드바 Slug(고유주소). 초안 저장 뒤 편집, 기본은 제목에서 자동. 고유주소 "기본(Plain)" 설정이면 편집 불가 | 같음 | [공식] 사이드바 문서 |

## 6. 권장 붙여넣기 방식 · 붙인 뒤 손볼 것

### 방식 비교

| 방식 | 장점 | 단점 | 등급 |
|---|---|---|---|
| A. **마크다운 일반 텍스트**를 비주얼 편집기 빈 문단에 붙이기 | 제목·목록·표·인용·구분선·코드·링크·굵게/기울임/취소선이 블록으로 바뀜. 서식 꼬임 적음 | 색·크기 없음, 각주 X, 단일 줄바꿈이 `<br>` 이 됨 | [공식-코드] |
| B. 렌더된 화면(리치 HTML) 복사 → 붙이기 | 같은 블록 변환 | 색·크기·class 사라짐, 인라인 style 전부 제거 | [공식-코드] |
| C. **블록 마크업**(`<!-- wp:... -->`) 텍스트를 붙이기(비주얼 또는 코드 편집기) | 변환 없이 그대로 블록. 블록 속성(정렬·색 등)까지 유지 | 마크업이 블록 save() 결과와 다르면 invalid 경고. 권한 없으면 kses 로 script/iframe 제거 | [공식-코드] · [공식] |
| D. 블록 주석 없는 HTML 을 코드 편집기에 | 원본 HTML 유지 | 전체가 클래식 블록 → "블록으로 변환" 필요 | [공식-코드] |

- 원고 생성 쪽 규칙 제안 [추정]:
  - 본문 제목은 `##`(H2)부터. 글 제목은 별도 칸에 넣으므로 본문 H1 은 피함(일반 SEO 관행, 공식 근거 확인 못 함).
  - 문단 사이는 빈 줄. 문단 안 줄바꿈 금지(줄바꿈이 `<br>` 로 남음).
  - 색·글자 크기 강조는 쓰지 말고 굵게/기울임/인용으로 대체(어차피 지워짐).
  - 표는 GFM 파이프 표, 셀 안 서식은 단순하게.
  - 이미지는 외부 URL 을 단독 줄 `![alt](https://...)` 로 → 이미지 블록이 됨, 붙인 뒤 업로드.
  - 동영상은 URL 단독 줄 → 임베드 블록.
  - 각주는 쓰지 말거나 본문 끝 일반 목록으로.
  - 발췌·태그·카테고리·슬러그·대표 이미지는 본문 밖 별도 항목으로 제공(태그는 쉼표 구분 한 줄로 주면 태그 칸에 한 번에 붙음).
  - `<!--more-->` 는 마크다운 텍스트 안에 한 줄로 두면 더보기 블록이 될 가능성 [추정, 미시험].

### 붙인 뒤 점검 목록

1. 이미지 블록마다 "Upload to Media Library" → 대체 텍스트 확인 → 하나를 대표 이미지로 지정. [공식-코드]
2. "사용자 지정 HTML" 블록으로 남은 것이 있는지 확인(변환 못 한 요소). [공식-코드]
3. 표 정렬·머리글 행(표 블록 설정에서 "Header section"). [추정]
4. 발췌·카테고리·태그·슬러그 입력(슬러그는 한글이면 영문으로 짧게 바꾸는 것 고려). [공식]/[추정]
5. 더보기 블록 위치(글당 1개). [공식]
6. WP.com 무료·호스팅 기능 꺼진 사이트면 iframe/script 가 저장 시 사라지므로 임베드 블록으로 바꿈. [공식]
7. 미리보기에서 줄바꿈(`<br>`) 남은 곳 정리. [공식-코드 기반 추정]
