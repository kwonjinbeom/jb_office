# AI 소식: OpenAI 모델 Google Cloud 입성, Gemini 앱 모델 접근 정리 (2026-10-22)

> OpenAI 의 GPT-6 계열 모델과 Codex 가 10월 21일 Google Cloud 에 들어왔지만, 지금은 선택된 기업 고객만 쓰는 비공개 프리뷰입니다. 개인 사용자에게 더 체감되는 쪽은 Gemini 앱으로, 무료는 가벼운 모델 중심으로 바뀌었고 최신 Gemini 4 Argon 은 유료 Pro·Ultra 에 먼저 열렸습니다.

## OpenAI 모델과 Codex — Google Cloud Model Garden 에서 비공개 프리뷰

GPT-6 Astra, GPT-6.1 Sol, GPT-6 Luna 세 모델이 Google Cloud 의 Model Garden 에 올라왔습니다. Astra 는 복잡한 코딩·컴퓨터 사용·연구용, Sol 은 Astra 에 가까운 성능에 비용을 낮춘 모델, Luna 는 빠르고 저렴한 일상 업무용입니다. 로컬 Codex CLI 와 데스크톱도 Google 쪽 추론에 연결할 수 있다고 합니다.

이미 Google Cloud 로 결제하는 회사에 쓸모가 있습니다. 구매는 Google Cloud Marketplace 에서 하고 기존 청구서와 사용 약정에 합쳐집니다. 대상은 관심 양식을 낸 일부 기업이고, 토큰 단가와 일반 공개 시점은 발표에 없습니다. 개인이 지금 쓸 수 있는 것은 아닙니다.

출처: TestingCatalog (2026-10-21), GeekNews (OpenAI 공지 소개, 2026-10-22)

## Gemini 앱 — 무료는 경량 모델 중심, Plus 는 Pro 제외

10월 9일부터 AI 구독이 없는 개인 계정은 자동 선택에서 대부분 Flash-Lite 로 답을 받고, 자동 선택을 끄면 항상 Flash-Lite 입니다. Google AI Plus 는 Flash-Lite 와 Flash 까지, Pro 모델은 빠집니다. Plus 는 계정마다 전환 시점을 이메일로 알려 준다고 하니 받은 메일을 확인해 보세요. AI Pro·Ultra 는 세 모델을 모두 씁니다.

깊은 추론이 필요한 질문을 무료나 Plus 로 자주 하는 분은 답 품질이 달라졌는지 비교해 볼 만합니다. 회사·학교 계정은 이 공지의 대상이 아닙니다.

출처: Google 도움말 "Changes to Gemini model access and limits" 인용 보도 (letsdatascience, 2026-10-03)

## Gemini 4 Argon — Gemini 앱에서 Pro·Ultra 구독자에게 먼저

10월 13일 Gemini 4 Argon 이 Gemini 앱에 들어왔고 Google AI Pro·Ultra 구독자가 고를 수 있습니다. 같은 요금제는 검색 AI 모드에서도 쓸 수 있습니다. 개발 환경인 Antigravity 는 Ultra 만 포함입니다.

무료 사용자 제공 여부, 국가·언어 지원, API 가격은 공식 글에 적혀 있지 않습니다. 한국어 지원 범위를 따지는 분은 Gemini 앱에서 직접 선택지를 확인하는 편이 정확합니다.

출처: Google 블로그 "Gemini 4 is now available in the Gemini app" (2026-10-13)

두 소식 모두 쓰는 요금제가 기준입니다. 무료나 Plus 라면 Pro 급 답이 필요한 질문만 Pro 로 올릴지 따져 보는 것이 지금 할 일입니다.
