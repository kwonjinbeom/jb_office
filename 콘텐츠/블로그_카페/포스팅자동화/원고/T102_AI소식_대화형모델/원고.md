# AI 소식 10/22 — GPT-6가 구글 클라우드에 들어오고, ChatGPT에 대화 잠금이 생겼어요

> 10월 22일 구글 클라우드가 OpenAI의 GPT-6 모델 3종을 Model Garden에 들였습니다. 지금은 일부 기업 고객 대상 비공개 프리뷰예요. ChatGPT에서는 10월 20일부터 대화를 PIN으로 잠그는 기능이 무료 사용자에게도 순차 적용됩니다.

## OpenAI 모델 — 구글 클라우드에서 쓸 수 있게 됐어요

구글 클라우드의 Model Garden에 GPT-6 Astra, GPT-6.1 Sol, GPT-6 Luna가 들어왔습니다. Astra는 코딩·컴퓨터 사용 같은 어려운 작업용, Sol은 Astra에 가까운 성능을 더 낮은 비용으로, Luna는 대량 업무용 빠른 모델이라고 소개돼요.

구글은 같은 클라우드에서 Gemini, Claude, GPT를 모두 고를 수 있는 곳이라고 밝혔습니다. 로컬에서 쓰는 Codex CLI와 데스크톱 작업도 Gemini 플랫폼 추론에 연결할 수 있어요. 결제는 Google Cloud Marketplace로 한 청구서에 모이고, 기존 클라우드 약정에서 차감됩니다.

지금은 일부 기업 고객 대상 비공개 프리뷰이고, 나머지는 관심 등록 폼으로 신청해야 합니다. 토큰당 가격은 공지에 없고, 데이터 무보관(ZDR)과 Confidential Compute는 "곧 제공"으로 적혀 있어요. 개인 사용자에게는 당장 달라지는 것이 없습니다.

출처: Google Cloud 블로그 (2026-10-22) https://cloud.google.com/blog/products/ai-machine-learning/google-cloud-brings-openai-models-to-customers

## ChatGPT — 대화를 잠글 수 있어요

대화창 더보기(•••) 메뉴에서 '채팅 잠금'을 고르면 그 대화가 일반 기록, 고정 목록, 검색에서 사라집니다. 열 때는 4자리 계정 PIN이나 기기 인증(지문·얼굴 등)을 써요. 보관 기간과 모델 개선 사용 설정은 그대로입니다.

휴대폰이나 PC를 가족과 같이 쓰거나 화면을 자주 보여 주는 분에게 쓸모 있어요. 다만 서버에서 지워지는 것은 아니라서, 데이터를 학습에 쓰지 않게 하려면 기존 데이터 설정을 따로 확인해야 합니다.

무료·Go·Plus·Pro 사용자에게 웹, iOS, Android, 새 데스크톱 앱(macOS·Windows)에서 순차 적용 중이에요. 추가 요금은 없습니다.
