# AGENTS.md 하나로 Claude Code·Codex·Gemini CLI·Copilot 지침 맞추기 (CLAUDE.md는 남길까 지울까)

<!-- 제휴가 있으면 이 줄에 대가성 문구 -->

코딩 에이전트를 두 개 이상 쓰면 "빌드는 이 명령, 테스트는 이 명령, 이 폴더는 건드리지 마" 같은 지침을 CLAUDE.md, AGENTS.md, GEMINI.md에 따로 적고 맞추는 일이 생긴다. 한쪽만 고치고 다른 쪽을 잊으면 에이전트마다 다르게 움직인다. **이제는 AGENTS.md 하나에 적고, 나머지는 그 파일을 가리키게만 하면 된다.** Claude Code가 v2.1.277부터 AGENTS.md를 직접 읽기 시작하면서 마지막 남은 구멍이 메워졌다.

다만 Claude Code는 조건이 붙는다. 그 조건을 모르면 "AGENTS.md를 만들었는데 왜 안 읽지?"가 된다. 도구별로 무엇을 읽는지부터 정리한다.

## 도구별로 무엇을 읽나

| 도구 | 기본으로 읽는 파일 | AGENTS.md | 확인 방법 |
|---|---|---|---|
| Codex | AGENTS.md | 기본 | 루트부터 현재 폴더까지 차례로 읽음 |
| GitHub Copilot | AGENTS.md, .github/copilot-instructions.md 등 | 기본 (가장 가까운 파일 우선) | 기능마다 지원 범위가 다름 |
| Gemini CLI | GEMINI.md | **설정해야 읽음** | `/memory show` |
| Claude Code | CLAUDE.md | **CLAUDE.md가 없을 때만** (v2.1.277+) | `/context` → Memory files |

결국 손댈 곳은 둘이다. Gemini CLI는 설정 한 줄, Claude Code는 CLAUDE.md와의 관계 정리.

## Claude Code가 AGENTS.md를 안 읽는 경우

기본 동작은 "CLAUDE.md가 있으면 그것만, 없으면 AGENTS.md"다. 여기서 '있으면'에 걸리는 파일은 작업 폴더와 그 위 폴더의 다음 셋이다.

- `CLAUDE.md`
- `.claude/CLAUDE.md`
- `CLAUDE.local.md`

반대로 `~/.claude/CLAUDE.md`(내 전역 지침), 회사가 배포한 관리 CLAUDE.md, `.claude/rules/` 파일은 이 판단에 들어가지 않는다. 이것들은 AGENTS.md와 같이 읽힌다.

가장 흔한 함정은 **CLAUDE.local.md**다. 팀은 AGENTS.md만 쓰는데, 나 혼자 커밋 안 할 메모를 CLAUDE.local.md에 적는 순간 내 Claude Code는 AGENTS.md를 더 이상 읽지 않는다. 이럴 땐 아래 '방법 3'처럼 설정을 바꾼다.

참고로 `AGENTS.override.md`, `AGENTS.local.md`, `.agents/` 폴더는 Codex 쪽 관례이고 Claude Code는 읽지 않는다.

## 파일 하나로 맞추는 방법 세 가지

### 방법 1. AGENTS.md만 두기 (가장 단순)

CLAUDE.md를 지우고 AGENTS.md만 둔다. 세션을 열면 `no CLAUDE.md found; AGENTS.md loaded: ...` 같은 줄이 대화에 보인다. Claude 전용으로 할 말이 없다면 이걸로 끝이다.

### 방법 2. CLAUDE.md에서 가져오기 (Claude 전용 지침이 있을 때)

```markdown
@AGENTS.md

## Claude Code 전용
- src/billing/ 아래 변경은 plan 모드로 먼저 계획을 보여 준다.
```

`@AGENTS.md`가 공통 지침을 그대로 펼쳐 넣고, 그 아래에 Claude에만 해당하는 내용을 덧붙인다. 버전이 낮거나 AGENTS.md 직접 읽기가 꺼진 세션에서도 동작하니 가장 안전하다. 이미 이렇게 쓰고 있었다면 그대로 둬도 된다. 공식 문서에 따르면 같은 파일을 두 번 읽지 않는다.

주의할 것은 **"AGENTS.md를 먼저 읽어라"라고 말로만 적어 둔 CLAUDE.md**다. 이건 가져오기가 아니라 부탁이라서, Claude가 그 파일을 열지 말지 스스로 정한다. `@AGENTS.md` 한 줄로 바꾸는 편이 확실하다.

### 방법 3. 둘 다 읽게 설정 바꾸기

세션에서 `/config`를 열고 **Project instructions** 값을 바꾼다.

| 값 | 읽는 것 |
|---|---|
| `claude-md-or-agents-md` | 기본. CLAUDE.md가 있으면 그것만, 없으면 AGENTS.md |
| `claude-md-and-agents-md` | 둘 다. 폴더마다 CLAUDE.md 먼저, AGENTS.md 다음 |
| `claude-md` | CLAUDE.md만 (예전 동작) |
| `managed-only` | 회사 관리 지침과 자동 메모리만 |

설정 파일로 박아 두려면 `~/.claude/settings.json`에 넣는다. 프로젝트의 `.claude/settings.json`에 넣으면 무시된다는 점이 헷갈리기 쉽다.

```json
{
  "pluginConfigs": {
    "cc-plugin-agents-md@builtin": {
      "options": { "instructionFiles": "claude-md-and-agents-md" }
    }
  }
}
```

## 윈도우에서는 심볼릭 링크 대신 가져오기

`ln -s AGENTS.md CLAUDE.md`도 흔히 쓰는 방법이지만, 팀에 윈도우 사용자가 한 명이라도 있으면 피하는 게 낫다. 윈도우에서 링크를 만들려면 관리자 권한이나 개발자 모드가 필요하고, Git의 `core.symlinks`가 꺼진 클론에서는 링크가 **경로 한 줄만 적힌 텍스트 파일**로 풀린다. 그러면 그 사람의 Claude Code는 지침 대신 "AGENTS.md"라는 글자 하나를 읽는다. 방법 2의 `@AGENTS.md`가 운영체제를 타지 않는다.

## Gemini CLI는 설정 한 줄

Gemini CLI는 기본으로 GEMINI.md만 찾는다. `settings.json`의 `context.fileName`에 목록으로 넣으면 AGENTS.md도 읽는다.

```json
{
  "context": {
    "fileName": ["AGENTS.md", "GEMINI.md"]
  }
}
```

적용 뒤 `/memory reload`로 다시 읽고 `/memory show`로 실제로 들어갔는지 본다.

## 복사해 쓰는 AGENTS.md 뼈대

[그림] 저장소 루트에 AGENTS.md 하나, CLAUDE.md는 @AGENTS.md로 가리키고, Gemini CLI는 설정으로 가리키는 구조도

```markdown
# 프로젝트 지침

## 명령
- 설치: npm ci
- 개발 서버: npm run dev
- 테스트: npm test (커밋 전 꼭 실행)
- 린트: npm run lint

## 구조
- src/api/ : 서버 호출. 직접 fetch 하지 말고 src/api/client.ts 사용
- src/legacy/ : 수정 금지 (읽기만)

## 규칙
- 들여쓰기 2칸, 세미콜론 없음
- 새 의존성 추가 전에 먼저 물어본다
- 커밋 메시지: feat:/fix:/docs: 접두사
```

쓸 때 기준은 단순하다.

- **검증할 수 있게 쓴다.** "코드를 깔끔하게"가 아니라 "커밋 전 npm test".
- **짧게 둔다.** Claude Code 문서는 파일 하나에 200줄 아래를 권하고, Codex는 합계 32KiB(기본값)를 넘으면 그 뒤를 읽지 않는다.
- **도구 이름을 쓰지 않는다.** 공통 파일에는 모든 에이전트에 맞는 말만. 도구 전용 내용은 방법 2처럼 각자 파일에.

## 정리

| 상황 | 할 일 |
|---|---|
| Claude 전용 지침 없음 | CLAUDE.md 지우고 AGENTS.md만 |
| Claude 전용 지침 있음 | CLAUDE.md 첫 줄에 `@AGENTS.md` |
| CLAUDE.local.md를 써야 함 | Project instructions → `claude-md-and-agents-md` |
| 팀에 윈도우 사용자 있음 | 심볼릭 링크 말고 `@AGENTS.md` |
| Gemini CLI도 씀 | `context.fileName`에 AGENTS.md 추가 |

마지막으로 꼭 확인한다. Claude Code는 `/context`, Gemini CLI는 `/memory show`. 지침 파일은 "썼다"보다 "읽혔다"가 중요하다.
