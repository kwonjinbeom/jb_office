# 코딩 에이전트 소식 3가지 — Copilot 모델 교체, Claude Code 자동 모드 설정, Codex 중간 개입 (2026-10-22)

> GitHub Copilot에서 GPT-5.5·GPT-5.4 등 6개 모델이 10월 19일 빠졌고, 11월 16일에는 Claude Opus 4.8·Opus 5·GPT-5.6 Terra도 빠집니다. 모델을 고정해 쓰는 분은 대체 모델로 옮겨 둬야 합니다.

## GitHub Copilot — 모델 6개 폐기, 3개는 11월 16일

10월 19일에 Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Grok 4.5가 Copilot에서 폐기됐습니다. 대체는 각각 Gemini 3.8 Flash, GPT-6.1 Sol, GPT-6 Luna, Grok 4.7입니다. 모델 선택을 직접 지정해 둔 설정이나 연동이 있다면 바꿔야 합니다.

다음 폐기는 11월 16일입니다. Claude Opus 4.8·Opus 5는 Opus 5.5로, GPT-5.6 Terra는 GPT-6.1 Sol 또는 GPT-6 Luna로 대체됩니다. Opus 4.8은 연간 플랜 개인 구독자에게는 남습니다.

출처: github.blog/changelog 2026-10-19, 2026-10-15

## Claude Code — /auto-mode-setup 추가, 이어하기 전 사용량 경고

v2.1.304(10월 19일)에 `/auto-mode-setup`이 생겼습니다. 프로젝트와 최근 세션을 읽어서 자동 모드가 내 환경을 알도록 안내해 주는 설정이고, Bedrock·Vertex·Foundry 등에서도 됩니다. 무엇을 쓰는지는 릴리스 노트에 자세히 없어서 실행 전 문서를 확인하는 편이 안전합니다.

Pro·Max에서는 오래 쉰 대화를 이어 열 때 5시간 한도의 상당 부분을 쓸 것 같으면 "그래도 이어하기 / 새 대화" 중에 고르라는 경고가 뜹니다. `claude --worktree`는 HEAD가 분리돼 있거나 다른 브랜치일 때 종료 시 삭제 전에 먼저 묻습니다. 커밋이 날아가는 일을 막는 변경입니다.

출처: github.com/anthropics/claude-code/releases/tag/v2.1.304

## Codex — 응답 중에 말을 걸어 방향을 바꿀 수 있다

Codex CLI 0.163.0(10월 15일)은 에이전트가 답하는 도중에 후속 메시지를 보내 방향을 바꾸는 기능을 넣었습니다. 잘못된 방향으로 가는 걸 끝까지 기다리지 않아도 됩니다. `/config` 검색 패널, 리더 키(기본 Ctrl+X), 읽기 전용 도구 병렬 실행도 같이 들어왔습니다.

ChatGPT 로그인으로 쓰는 Codex에서는 10월 14일에 GPT-5.5가 종료되고 gpt-6.1-sol로 대체됐습니다. API 키로 쓰는 세션은 영향이 없습니다. 날짜가 72시간보다 앞선 건 Copilot 항목의 GPT-5.5 폐기와 이어지는 내용이라 함께 적었습니다.

출처: learn.chatgpt.com/docs/changelog

세 곳 모두 가격 변동은 공지에 없습니다. 오늘 할 일은 Copilot에서 모델이 폐기된 걸 쓰고 있는지 확인하는 것 하나입니다.

참고: github.blog/changelog, github.com/anthropics/claude-code/releases, learn.chatgpt.com/docs/changelog (2026-10-22 확인)
