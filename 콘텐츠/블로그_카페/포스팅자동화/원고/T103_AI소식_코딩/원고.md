# 코딩 AI 소식: Codex가 구글 클라우드로, Claude Code는 자동 모드 설정 도우미 추가 (2026-10-22)

> OpenAI가 10월 21일 자사 모델과 Codex 워크플로를 Google Cloud Model Garden에 들여온다고 발표했습니다. 지금은 일부 기업 고객 대상 비공개 미리보기입니다. Claude Code는 10월 19일 버전 2.1.304에서 자동 모드를 내 프로젝트에 맞춰 주는 /auto-mode-setup 을 추가했습니다.

## OpenAI Codex — 구글 클라우드에서 쓸 수 있게 됩니다

OpenAI 모델 GPT-6 Astra, GPT-6.1 Sol, GPT-6 Luna와 Codex 워크플로가 Google Cloud Model Garden에 들어옵니다. 내 컴퓨터의 Codex CLI와 데스크톱 앱을 Google Cloud에 연결해 모델 추론을 돌릴 수 있고, API로 자체 에이전트도 만들 수 있습니다.

회사가 이미 Google Cloud를 쓰고 있다면 계정과 청구를 하나로 두고 쓸 수 있어 쓸모가 있습니다. 사용은 신청 양식을 낸 일부 기업 고객부터 순서대로 열립니다. 결제는 Google Cloud Marketplace에서 하나로 청구되고 기존 사용 약정을 적용할 수 있습니다. 토큰당 가격은 공개되지 않았고, 일반 공개는 "앞으로 몇 주 안"이라고만 밝혔습니다. 개인 사용자에게 열린 기능은 아닙니다.

출처: openai.com/index/openai-models-google-cloud, news.hada.io/topic?id=35775

## Claude Code — /auto-mode-setup 으로 자동 모드를 내 환경에 맞춥니다

2.1.304(10월 19일)에서 /auto-mode-setup 이 생겼습니다. 프로젝트와 최근 세션을 읽고 자동 모드에 내 작업 환경을 알려 주는 안내형 설정입니다. 자동 모드의 허용·확인 기준을 직접 적을 필요가 줄어듭니다. Bedrock, Vertex, Foundry 환경에서도 쓸 수 있습니다.

같은 버전에서 /claude-api managed-agents-secure 도 추가됐습니다. Managed Agents 설정을 Anthropic 보안 가이드와 비교해 보여 주기만 하고 설정을 바꾸지는 않습니다. 10월 21일 2.1.307에서는 /claude-api api-version 이 들어와 Claude API 코드를 API 버전 2026-10-21로 옮겨 줍니다. 팀에서 도구 호출 차단·확인 기록을 모으려면 새 claude_code.safety_event 이벤트를 OpenTelemetry로 받으면 됩니다. 가격 변화는 공지에 없습니다.

출처: github.com/anthropics/claude-code/releases (2.1.304, 2.1.307)

## 이번 소식이 맞지 않는 분

개인으로 Codex를 쓰는 분은 구글 클라우드 연동의 대상이 아니라서 지금 바뀌는 것이 없습니다. Claude Code 를 쓰지 않는다면 두 번째 항목도 해당하지 않습니다. 일반 공개 날짜가 정해지면 첫 항목부터 다시 확인하는 것이 좋겠습니다.
