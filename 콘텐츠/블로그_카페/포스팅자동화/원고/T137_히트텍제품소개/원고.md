## 내 하루로 고르면 이렇게 돼요

고르는 기준은 셋이에요. 밖에 있는 시간이 얼마인지, 실내 난방이 센지, 땀을 얼마나 흘리는지.

| 내 하루 | 고를 단계 |
|---|---|
| 지하철 출퇴근, 하루 대부분 사무실·교실 | 기본 |
| 걸어서 10~20분 출퇴근, 추위 타는 편 | 엑스트라웜 |
| 부모님 선물 (아침 산책·시장 나들이) | 엑스트라웜 |
| 야외 근무·주차 관리·배달 | 울트라웜 |
| 겨울 캠핑·스키·산행 | 울트라웜, 땀 많이 나는 산행은 기본 |
| 땀이 잘 나고 많이 움직임 | 기본 (두꺼울수록 덥고 땀이 차요) |

이미 두꺼운 패딩을 입는다면 안쪽까지 울트라웜으로 맞출 필요는 크지 않아요. 겉옷이 얇은 코트라면 엑스트라웜으로 한 단계 올리는 쪽이 체감이 커요.

빨래는 세 단계 모두 세탁망에 넣는 편이 안전해요. 울트라웜은 건조기를 쓰지 말라고 공식 안내돼 있어요.

추위를 얼마나 타는지 모르겠다면 엑스트라웜 하나로 시작해 보세요. 실내에서 덥다고 느끼면 다음엔 기본을, 밖에서도 춥다면 울트라웜을 더하면 돼요.
