# 슬램덩크 애니 101화 다음은 만화 몇 권부터? 화수 환산기·산왕전과 더 퍼스트 슬램덩크

슬램덩크 애니 몇 화가 만화 몇 화·몇 권인지, 아래 환산기에 화수를 넣으면 바로 나와요.

## 애니는 만화 어디까지?

슬램덩크 애니는 시즌 없이 101화로 끝나요. 만화 197화(22권 끝)까지를 96화에 담았고, 97~101화는 애니 오리지널 결말이에요. 만화는 276화·31권으로 완결이라, 뒷부분(산왕전)은 만화로 봐야 해요.

| 구분 | 애니 | 만화 |
|---|---|---|
| 원작 내용 | 1~96화 | 1~197화 (1~22권) |
| 애니 오리지널 결말 | 97~101화 | 없음 |
| 애니에 없는 부분 | - | 198~276화 (23~31권) |

![슬램덩크 애니, 어디까지 만화 내용일까](https://raw.githubusercontent.com/kwonjinbeom/jb_office/main/%EC%BD%98%ED%85%90%EC%B8%A0/%EB%B8%94%EB%A1%9C%EA%B7%B8_%EC%B9%B4%ED%8E%98/memorily_%ED%8B%B0%EC%8A%A4%ED%86%A0%EB%A6%AC/%EC%95%A0%EB%8B%88%ED%99%98%EC%82%B0%EA%B8%B0/%EC%82%AC%EC%A7%84/slamdunk-chart.png)

## 장별 대응

| 장 | 애니 | 만화 |
|---|---|---|
| 농구부 입부 | 1~8화 | 1~16화 (1~2권) |
| 능남 연습경기 | 9~20화 | 17~50화 (2~6권) |
| 미야기 합류·정대만 사건 | 21~27화 | 51~71화 (6~8권) |
| 인터하이 예선 | 28~49화 | 72~98화 (9~11권) |
| 해남전 | 50~59화 | 99~131화 (12~15권) |
| 결승리그 | 60~84화 | 132~185화 (15~21권) |
| 전국대회 앞 | 85~96화 | 186~197화 (21~22권) |

장 이름은 큰 흐름으로 나눈 거예요. 화수 범위는 회차마다 맞춰 본 값이라, 몇 화 안팎은 겹칠 수 있어요.

## 애니 다음 만화는

애니 96화가 만화 197화에서 끝나서, 이어 읽으려면 198화(23권)부터예요. 만화는 31권 완결이에요. 산왕공고와의 경기는 애니에 없고, 극장판 〈더 퍼스트 슬램덩크〉가 그 이야기를 새로 그렸어요.

## 애니 오리지널 회차

| 회차 | 내용 |
|---|---|
| 34·35화 | 오리지널 (채치수 이야기, 열혈 사나이들) |
| 48·49화 | 오리지널 (해남을 이기겠다고 맹세한 녀석, 마지막 시합) |
| 85·86화 | 오리지널 (전국을 향한 새 도전, 서태웅의 야망) |
| 95화 | 오리지널 (강백호의 가장 뜨거운 날) |
| 97~101화 | 오리지널 결말 |

섞인 회차도 있어요. 31·32·36·90화는 만화에 애니 장면이 섞였고, 47화는 앞 11분 정도만, 92화는 19분 뒤부터만 만화 내용이에요 (Anime Filler Guide 기준).
