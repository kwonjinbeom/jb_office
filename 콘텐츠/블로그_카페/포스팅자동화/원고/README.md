게시 적기가 급한 순서로 놓았다. 경험 글(편의점 디저트·할로윈)은 사진과 메모가 없어 이번에는 단풍으로 바꿨다. 사진이 생기면 바로 경험 글로 시험한다.

## 지금 보이는 사용자의 역할

원고를 만들면서 AI가 **대신할 수 없었던 것**만 남겼다. 각 원고의 '손질하면 좋아지는 곳'에 구체적으로 적어 두었다.

1. **내 경험 한 줄:** "제 다이어리는 4월에 멈췄어요" 같은 문장. 이것 하나로 정보 글이 내 글이 된다.
2. **내 사진:** 대표 사진이나 증거 사진 한 장.
3. **수익 연결 선택:** 어떤 제품에 제휴 링크를 넣을지. 넣으면 대가성 문구도 함께 넣는다.
4. **확인 못 한 사실 하나 정리:** 예) 지리산 날짜. 원고마다 '확인한 사실' 표에 표시해 두었다.
5. **게시.**

나머지(주제 선정, 사실 확인, 구성, 문장, 도식, 태그)는 AI가 맡는다. 이 역할 구분은 손질해 보고 바꿔 나간다.
