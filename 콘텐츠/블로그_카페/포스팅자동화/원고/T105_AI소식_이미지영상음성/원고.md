# AI 영상 새 모델 FLUX 3 Max, 10초 클립 12초 생성 (2026-10 넷째 주)

> fal 이 10월 19일 영상 생성 모델 FLUX 3 Max 를 내놨습니다. 10초 클립을 평균 12.45초에 만들고, 같은 조건에서 Seedance 2.5 는 277.80초였다는 것이 fal 의 자체 측정입니다. 첫 3주는 API 가격이 75% 할인됩니다.

## FLUX 3 Max — 영상 생성 속도를 올린 신모델

fal 과 Black Forest Labs 가 FLUX 3 Video 를 후속 학습해서 속도를 올린 모델입니다. 텍스트→영상, 이미지→영상을 지원하고, 끝 프레임 지정과 키프레임 최대 10장, 5~20초 길이, 소리 켜고 끄기가 됩니다. 기본 720p 에 1080p 업스케일이 가능합니다.

빠르게 여러 컷을 뽑아 비교해야 하는 쇼츠·광고 시안 작업에 맞습니다. 품질은 Artificial Analysis 의 이미지→영상 평가에서 Seedance 2.5 와 같은 1139 Elo 라서, 속도만 앞선다고 보면 됩니다. 이 평가는 이미지→영상만 다루고 속도 수치는 fal 이 직접 잰 값입니다.

| 해상도 | 정가(초당) | 10초 클립 |
|---|---|---|
| 720p | $0.17 | $1.70 |
| 1080p | $0.29 | $2.90 |

확인일 2026-10-22. 첫 3주는 75% 할인이고 API 로 만든 결과물은 이용약관 안에서 상업적으로 쓸 수 있습니다. 개발자용 API 형태라 앱처럼 바로 눌러 쓰는 서비스는 아니며, 한국어 프롬프트 지원 여부는 확인하지 못했습니다.

## Runway — MCP 에 음성·효과음·이미지 모델 추가

Runway 변경 기록에 10월 12~15일 사이 네 가지가 올라왔습니다. 모두 유료 플랜에서 Runway MCP 로 쓰는 기능입니다.

- Fish Audio Drama 3 (10-14): 대본을 내레이션으로 바꿉니다. 목소리 7종, 속삭임·웃음 같은 연출 큐를 지원합니다.
- Mirelo SFX 2.0 (10-15): 영상 클립과 원하는 소리 설명으로 효과음 트랙을 만듭니다.
- BiRefNet v2 (10-15): 배경을 자동으로 지웁니다.
- Seedream 5.0 Flash (10-12): 텍스트나 참조 이미지 최대 10장으로 1K·2K 이미지를 만듭니다.

영상 하나를 만들고 내레이션·효과음까지 한 도구에서 끝내려는 사람에게 쓸모가 있습니다. 반대로 MCP 를 쓰지 않고 웹 화면만 쓰는 사람에게는 당장 바뀌는 것이 없습니다.
