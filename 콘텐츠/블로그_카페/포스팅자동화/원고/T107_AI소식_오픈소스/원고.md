# 오픈소스 AI 소식: DeepSeek V4.1 Flash 업데이트, Ollama에 Clef 추가 (2026-10-22)

> DeepSeek이 V4.1 Flash를 업데이트한 1017 버전을 MIT 라이선스로 공개했고, Hugging Face 트렌딩 1위에 올랐습니다. Cloudflare의 27B 결정 모델 Clef는 10월 19일 Ollama에 올라와 로컬에서 받아 쓸 수 있습니다.

## DeepSeek V4.1 Flash 1017 — 코딩·에이전트 점수를 올린 마이너 업데이트

기존 V4.1 Flash 대비 DeepSeek이 모델 카드에 적은 점수가 올랐습니다. Terminal-Bench 4.0 31.2 → 42.3, ProgramBench 20.3 → 29.1, 추론 시험 HLE(도구 없음) 36.8 → 42.6입니다. 실행 시간과 출력 길이도 줄여 API 비용이 낮아진다고 합니다. 같은 카드의 비교표에서 Opus 5는 대부분 항목에서 더 높습니다.

MIT 라이선스라 상업적 이용이 자유롭습니다. 다만 763B 모델이라 일반 PC에서는 돌릴 수 없고, 공식 배포는 FP8 가중치뿐입니다. 내 PC에서 쓰려면 커뮤니티 양자화본(약 96개, llama.cpp·Ollama·LM Studio용)을 받아야 하는데, 그래도 큰 메모리가 필요합니다. 점수 수치는 모두 DeepSeek 자체 발표입니다.

출처: huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017 (2026-10-17 등록)

## Ollama Clef — Cloudflare의 27B 결정 모델 추가

Clef는 상태와 질문 목록을 넣으면 결정을 돌려주는 모델입니다. 예/아니오 판단이나 선택지 점수 매기기 같은 분류형 작업에 맞춰져 있습니다. Qwen3.8-27B를 Cloudflare가 파인튜닝했고, 텍스트와 이미지를 입력받습니다.

라이선스는 Apache 2.0입니다. Ollama에서 로컬 실행도, Ollama 클라우드 실행도 됩니다. 필요한 메모리 사양은 공식 글에 적혀 있지 않아서, 27B급 모델이 기준이 될 텐데 정확한 수치는 확인하지 못했습니다. 채팅용이 아니라 자동화 흐름에 끼워 넣는 모델이라 대화만 하려는 분에게는 맞지 않습니다.

출처: ollama.com/blog/clef (2026-10-19)
