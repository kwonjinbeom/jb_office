# ChatGPT 잠금 채팅, Gemini 지도 기억, 노트북 코딩 모델 Flint (AI 소식 10-23)

> ChatGPT 에 대화를 4자리 PIN 이나 얼굴 인식으로 잠그는 '잠금 채팅'이 무료 요금제까지 순차 적용되고 있습니다. 노트북에서 인터넷 없이 돌리는 오픈 코딩 모델 Flint 가 나왔고, 구글 클라우드는 GPT 모델을 들여와 Gemini·Claude·GPT 를 한곳에서 파는 첫 대형 클라우드가 됐습니다.

## ChatGPT — 대화를 PIN 으로 잠그는 '잠금 채팅'

- 대화의 더보기 메뉴에서 "Lock chat"을 고르면 그 대화가 잠금 영역으로 옮겨집니다. 처음 잠글 때 4자리 PIN 을 만들고, 휴대폰에서는 Face ID·지문으로도 열 수 있어요. Projects 아래 '잠금 채팅'에서 처음부터 잠긴 대화를 시작할 수도 있습니다.
- 가족과 기기를 같이 쓰거나 건강·돈 이야기를 ChatGPT 에 묻는 분에게 쓸모 있습니다. Free·Go·Plus·Pro·Business·Enterprise·Edu 모두, 웹·iOS·안드로이드·맥·윈도우 앱에 10월 20일께부터 순차 적용 중이라 메뉴가 안 보이면 며칠 기다려야 합니다.
- 화면 잠금일 뿐 암호화는 아닙니다. 서버 보관 기간·학습 설정은 그대로이고, Enterprise·Edu 관리자는 감사 로그에서 내용을 볼 수 있습니다. PIN 을 잊어 재설정하면 잠긴 대화와 그 안의 메모리·파일이 **모두 지워지고** OpenAI 도 되살리지 못합니다.

출처: Tech Times (10월 21일)

## Gemini — 지도에서 찾은 곳·저장한 장소까지 기억

- Gemini 의 Personal Intelligence 가 구글 지도에서 내가 검색한 곳과 저장한 장소를 참고하게 됐습니다. 구글이 든 예는 캘린더와 함께 써서 "오늘 마지막 미팅 근처 가게"를 추천하는 식이에요.
- 지도에 맛집·가 볼 곳을 저장해 두는 분이라면 "저장해 둔 곳 중 비 오는 날 갈 만한 데" 같은 질문이 됩니다. 켜고 끄는 곳은 gemini.google.com/personalization-settings 입니다. 지원 국가·언어·요금제는 발표에 없어 한국에서 바로 되는지는 확인이 필요합니다.
- 같은 날 AI Ultra 구독자에게는 새 모델 Gemini 4 Argon 이 "곧 Deep Think 를 대신한다"는 안내가 떴습니다. Deep Think 모드 자체가 없어지는지는 아직 밝히지 않았어요.

출처: 9to5Google (10월 22일)

## Flint — 노트북에서 인터넷 없이 도는 오픈 코딩 모델

- 스타트업 Recursive 가 첫 모델 Flint 를 Apache 2.0 으로 허깅페이스에 무료 공개했습니다(10월 21일). 전체 400억 파라미터 중 한 번에 약 25억만 쓰는 구조라, M4 Pro 맥북 프로에서 초당 130토큰 안팎이 나온다고 회사가 밝혔습니다.
- 코드를 밖으로 보내기 어려운 회사 개발자, 구독료 없이 로컬 코딩 도우미를 쓰고 싶은 분이 볼 만합니다. 다만 메모리 48GB 이상을 권하고, 4비트로 줄여도 그래픽 메모리 약 26GB 가 듭니다. 큰 작업은 잘게 나눠 시켜야 한다고 회사도 말합니다.
- 써 본 사람들은 빠르다는 데는 대체로 동의합니다. RTX 5090 에서 돌린 테스트는 에이전트 과제 18번 중 12번을 통과했지만, 로그 줄 수를 직접 세지 않고 숫자를 지어낸 경우가 있었습니다. 다른 리뷰에서는 문맥이 11만 토큰 근처까지 길어지자 초당 9토큰까지 느려졌다고 합니다. 벤치마크 점수는 대부분 회사 발표입니다.

출처: TechCrunch (10월 21일), Atomic Agent 테스트 (10월 22일), daily.dev 리뷰

## 구글 클라우드 — GPT 모델 입점, 세 회사 모델을 한곳에서

- 구글 클라우드가 OpenAI 의 GPT-6 Astra(코딩·리서치), GPT-6.1 Sol(값싼 대안), GPT-6 Luna(빠른 일상용)를 비공개 프리뷰로 들여왔습니다(10월 21일 발표). Gemini for Business 와 Google Antigravity 에도 들어갈 예정입니다.
- 이미 구글 클라우드를 쓰는 회사라면 계약·청구서 하나로 Gemini·Claude·GPT 를 골라 쓰게 됩니다. 지금은 신청한 일부 기업 고객만 쓸 수 있고 가격은 나오지 않았습니다. 개인 사용자에게 당장 바뀌는 건 없습니다.

출처: The Decoder (10월 21일), AI타임스 (10월 22일)

## Agent Skills — 70개 넘는 도구가 쓰는 규격, 중립 재단으로

- 앤트로픽이 Agent Skills 규격을 리눅스재단 산하 Agentic AI Foundation 에 기증했습니다(10월 22일). MCP 를 맡긴 그 재단이고, 앞으로 앤트로픽·구글·OpenAI 엔지니어가 함께 관리합니다.
- 스킬은 SKILL.md 파일과 스크립트가 든 폴더 하나입니다. ChatGPT·Cursor·GitHub Copilot·VS Code 등 70개 넘는 도구가 이미 읽을 수 있어서, 한 번 만든 스킬을 도구를 바꿔도 그대로 쓴다는 점이 더 단단해졌어요. 지금까지 스킬 100만 개가 올라왔고 설치는 약 2억8천만 번입니다.
- 쓰는 사람에게 당장 달라지는 건 없습니다. 버전 관리·공식 제안 절차·스킬 보안 가이드가 로드맵에 올라 있습니다.

출처: Anthropic 뉴스룸 (10월 22일)

## Claude Security — 저장소를 계속 지켜보는 보안 검사 (Enterprise)

- 코드 보안 검사 도구 Claude Security 새 버전이 공개 베타로 나왔습니다(10월 21일). 한 번 검사하고 끝이 아니라 연결된 저장소가 바뀔 때마다 다시 점검하고, 고친 취약점이 다시 생기면 '미해결'로 되돌립니다.
- 대상은 Claude Enterprise 고객뿐입니다. GitHub·GitHub Enterprise Server·GitLab 을 연결하고, claude.ai 와 Claude Code 에서 쓰는 MCP 커넥터도 줍니다. 두 달 동안 매월 2만5천 달러어치 무료 크레딧(12월 31일 사용분까지)이 붙습니다.

출처: AI타임스 (10월 22일)
