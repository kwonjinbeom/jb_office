# Kimi K3.1 Pro 공개, Claude 엔터프라이즈 채팅·Cowork 하나로, 구글 개인화 데이터가 광고에 (AI 소식 10-25)

> 중국 문샷AI 가 Claude Opus 5.5 의 절반 값인 새 모델 Kimi K3.1 Pro 를 내놨습니다. 앤트로픽은 기업용 Claude 에서 채팅과 Cowork 를 하나로 합쳤고, 구글은 Gemini 개인화를 켠 사람의 지메일·포토 데이터가 광고에 쓰일 수 있도록 방침을 바꿨습니다.

## Kimi K3.1 Pro — Opus 절반 값, 100만 토큰 문맥

- 문샷AI 가 10월 23일 Kimi K3.1 Pro 를 출시했습니다. 새 기반 모델이 아니라 K3 를 더 학습시킨 업그레이드이고, 한 번에 100만 토큰(책 여러 권 분량)을 읽습니다. kimi.com 웹·앱, Kimi Work·Kimi Code, API 에서 바로 쓸 수 있어요.
- API 값은 100만 토큰당 입력 2달러·출력 10달러로 K3(3/15달러)보다 내렸습니다. Claude Opus 5.5 의 절반이라 긴 문서·코드를 많이 돌리는 개발자가 볼 만합니다. 2~3배 빠른 Highspeed 판은 4/20달러입니다.
- 무료 요금제에서 쓸 수 있는지는 발표에 없습니다. 내려받아 직접 돌릴 수 있는 공개 가중치는 **11월 4일**까지 풀겠다고 했고, 라이선스는 아직 미정입니다.
- 써 본 사람들은 평가가 갈립니다. 독립 평가 Artificial Analysis 는 지수 55점(전작보다 11점 위)으로 전체 4위에 올렸지만, 답이 길어 실제 과제당 비용은 토큰 값만큼 싸지 않다고 봤습니다. 실무 코딩 과제 6종을 돌린 KingBench 는 10점 만점에 5.37점으로, 뼈대는 잘 짜는데 요청한 범위를 끝까지 마치지 못하는 경향을 짚었어요. Hacker News 에서는 K3 보다 두 배 가까이 빠르다는 말과 함께, 가끔 스스로를 ChatGPT 라고 소개한다는 후기도 나왔습니다.

## Claude Enterprise — 채팅과 Cowork 가 하나로 정식 출시

- 기업용 Claude Enterprise 에서 채팅과 Cowork 가 하나가 됐습니다(10월 23일). 모드를 고르지 않고 대화를 시작하면 짧은 질문은 바로 답하고, 코드·파일이 필요한 일은 클라우드에서 돌려 문서·분석·발표 자료로 돌려줍니다. 노트북을 닫아도 작업은 계속됩니다.
- 회사 관리자에게 쓸모 있는 건 비용 조절 장치입니다. Sonnet·Haiku 만 쓰게 묶는 Efficient mode, 역할별 모델 권한, 조직·그룹·개인별 지출 한도를 걸 수 있어요. 에이전트 작업은 일반 채팅보다 토큰을 많이 쓰기 때문입니다.
- 기존 조직은 꺼진 채로 시작해 **11월 16일**에 자동으로 켜집니다. 먼저 쓰려면 관리자가 Organization settings › Capabilities 에서 켜면 됩니다. 데이터 미보관(ZDR)·HIPAA 구성·자체 암호화 키를 쓰는 조직은 지금 구성 그대로 남습니다. Pro·Max 개인 요금제는 9월에 이미 바뀌었어요.

출처: Claude 발표 글 claude.com (10월 23일), Claude 고객센터

## 구글 — Gemini 개인화를 켜면 지메일·포토 데이터가 광고에 쓰일 수 있음

- 구글이 개인정보처리방침을 바꿔, 검색이나 Gemini 앱이 지메일·드라이브·포토를 읽도록 허락한 사람은 그 데이터로 광고를 맞춤화할 수 있게 했습니다. 10월 16일 시행분이 23~24일 보도로 알려졌어요. 2021년부터 지켜 온 '메일 내용은 광고에 안 쓴다'는 약속에 예외가 생긴 셈입니다.
- 지난 소식에서 다룬 Gemini 지도 연동처럼 Personal Intelligence(개인화)를 켠 분이 해당됩니다. 켜지 않았다면 바뀌는 게 없습니다. 광고주는 이름·이메일·메일함·사진 원본을 받지 않고, 건강·종교 같은 민감 범주는 빠진다고 구글은 밝혔습니다. Gemini 앱 자체에는 아직 광고가 없지만, 개인화를 켠 사람 대상으로 검색 AI 모드 광고를 시험 중입니다.
- 꺼림칙하면 개인화 설정에서 연결한 앱을 끊거나 맞춤 추천을 끄면 됩니다. 이미 저장된 데이터는 검색 기록에 남을 수 있어 따로 지워야 해요. 발표 기준 대상은 유럽경제지역·스위스·영국·나이지리아를 뺀 18세 이상이고, 한국 계정에 언제 어떻게 적용되는지는 따로 밝히지 않았습니다.
