# 2026 월드시리즈 한국시간 일정: 10월 24일 토요일 오전 9시 개막, 어디서 볼까

> 월드시리즈 1차전은 한국시간 10월 24일(토) 오전 9시에 시작해요. 브루어스와 레이스의 7전 4승제이고, 한국에서는 SPOTV NOW로 볼 수 있어요.

## 한국시간으로 몇 시에 하나요?
모든 경기가 미국 동부 현지 오후 8시에 시작해서, 한국시간으로는 다음 날 오전 9시예요. (10월 22일 확인)

| 차전 | 한국시간 | 홈구장 | 비고 |
|---|---|---|---|
| 1차전 | 10/24(토) 09:00 | 밀워키 | |
| 2차전 | 10/25(일) 09:00 | 밀워키 | |
| 3차전 | 10/27(화) 09:00 | 탬파베이 | |
| 4차전 | 10/28(수) 09:00 | 탬파베이 | |
| 5차전 | 10/29(목) 09:00 | 탬파베이 | 필요 시 |
| 6차전 | 10/31(토) 09:00 | 밀워키 | 필요 시 |
| 7차전 | 11/1(일) 09:00 | 밀워키 | 필요 시 |

1·2차전이 주말 아침이라 부담이 적어요. 3~5차전은 평일 출근 시간과 겹쳐요.

## 어디서 볼 수 있나요?
- 한국: SPOTV NOW에서 생중계해요. 월드시리즈 전 경기를 SPOTV가 10/24~11/1 일정으로 안내했어요.
- 미국 현지는 FOX와 FOX One이에요. 한국 시청 경로는 SPOTV로 보면 돼요.
- 쿠팡플레이·티빙은 MLB 중계가 아니에요 (K리그와 KBO 쪽).
- 방송 채널 편성과 이용권 요금은 바뀔 수 있어서, 보기 전날 SPOTV 편성표에서 한 번 더 보세요.

## 처음 보는 사람은 이것만 알면 돼요
- 7전 4승제: 4번 먼저 이기는 팀이 우승이에요. 4승이 빨리 나오면 5~7차전은 열리지 않아요.
- 홈 어드밴티지: 정규시즌 승수가 더 많은 브루어스(103승)가 1·2·6·7차전을 홈에서 치러요. 레이스(98승)는 3·4·5차전 홈이에요.
- 2차전 뒤 이동일이 하루 있어서, 한국시간 10/26(월)에는 경기가 없어요.

## 이런 분께는 안 맞을 수 있어요
아침 9시에 3시간 안팎으로 보기 어렵다면 SPOTV NOW 다시보기로 보는 편이 나아요. 다시보기 제공 여부는 이용권에 따라 달라서 결제 전에 확인하세요.

토요일 아침 1차전 알람은 8시 50분에 맞추면 돼요.
