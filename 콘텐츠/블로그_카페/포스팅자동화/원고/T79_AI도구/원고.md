# Claude Sonnet 5.5 vs Opus 5.5, 보고서·슬라이드·엑셀 일에는 뭘 골라야 할까

<!-- 제휴가 있으면 이 줄에 대가성 문구 -->

> 문서·슬라이드·스프레드시트 같은 사무 일은 Sonnet 5.5 로 시작하면 돼요. 사무 업무 평가(GDPval-AA)에서 Sonnet 5.5 는 1844점, Opus 5.5 는 1846점으로 거의 같고, 단가는 Sonnet 이 절반($2/$10 대 $4/$20)이에요. 판단이 복잡하고 답이 열려 있는 일만 Opus 로 올리세요.

## 두 모델은 어디가 다를까요?

확인일은 10월 21일이고, 가격은 100만 토큰 기준이에요.

| | Sonnet 5.5 | Opus 5.5 |
|---|---|---|
| 발표일 | 9월 28일 | 9월 22일 |
| 입력 / 출력 | $2 / $10 | $4 / $20 |
| 캐시 읽기 | $0.10 | $0.20 |
| 발표문이 말하는 강점 | 범위가 분명한 일상 업무, 문서·슬라이드·스프레드시트 | 복잡하고 열린 작업 |
| 사무 업무 평가 GDPval-AA | 1844 | 1846 |

두 모델의 점수 차이는 2점이에요. 발표문도 최상위 모델끼리의 점수 차이가 실제 차이를 그대로 보여주지는 않는다고 밝혀요.

## 보고서 한 건에 얼마나 들까요?

입력 20,000토큰(자료 여러 장), 출력 4,000토큰(보고서 한 편)을 가정했어요. 한글 토큰 수는 달라질 수 있으니 본인 usage 값으로 바꿔 보세요.

| 모델 | 1건 | 100건 |
|---|---|---|
| Sonnet 5.5 | $0.08 | $8 |
| Opus 5.5 | $0.16 | $16 |

계산은 `(입력 × 입력단가 + 출력 × 출력단가) ÷ 1,000,000` 이에요. 한 달에 몇십 건이면 차이가 몇 달러 수준이라 단가보다 결과 품질이 먼저예요. 다만 공식 발표문의 건당 비용은 모델마다 같은 일에 쓰는 토큰 수가 달라서 위 표와 다를 수 있어요.

## 언제 Opus 로 올릴까요?

- 자료가 흩어져 있고 결론을 스스로 만들어야 하는 보고서
- 재무 모델과 발표 자료를 한 번에 만드는 일. Opus 5.5 발표문 테스트에서 63분(Opus 5 는 93분) 걸렸어요.
- 틀리면 손해가 큰 분석. 이때는 모델과 상관없이 사람이 검토해야 해요.

양식이 정해진 주간 보고, 슬라이드 템플릿 채우기, 표 정리는 Sonnet 5.5 로 충분해요. 발표문은 Sonnet 5.5 가 슬라이드 템플릿을 따라 거의 수정 없이 쓸 덱을 만든다고 소개해요.

## 알아 둘 한계는요?

- Opus 5.5 는 thinking 을 끌 수 없어서 가벼운 일에도 생각하는 시간이 들어요.
- Sonnet 5.5 는 Max effort 가 항상 최고 점수는 아니에요. 발표문 기준으로 한 평가에서 Max 가 Xhigh 보다 낮았어요. 기본값(앱 Medium)에서 시작하세요.
- 사이버 보안·일부 생물학 요청은 안전장치로 다른 모델에 넘어가거나 막힐 수 있어요.
- 요금제별로 어떤 모델을 고를 수 있는지는 발표문에 없어서 앱의 모델 선택 화면에서 확인해야 해요.

맞지 않는 사람도 있어요. 하루 한두 건만 쓴다면 모델 비교에 시간을 쓰기보다 지금 쓰는 모델을 그대로 쓰는 편이 나아요.

양식이 있는 문서 하나를 Sonnet 5.5 로 만들어 보고, 고칠 곳이 많을 때만 Opus 5.5 로 바꿔 보세요.
