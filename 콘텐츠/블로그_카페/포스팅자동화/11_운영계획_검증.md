## 3. 통계 자동 연결

자동 = 서버가 주기적으로 가져온다 · 수동 = 사용자가 화면에서 보고 입력한다 · 불가 = 방법이 없다

| 항목 | 티스토리 (memorily·눈잎) | 네이버 블로그 |
|---|---|---|
| 발행 글 수 | **자동** — `https://<블로그>.tistory.com/rss`. 10-16 확인: notice.tistory.com 피드에 30건. 노출 개수는 블로그 설정에 따른다 | **자동** — `https://rss.blog.naver.com/<아이디>.xml`. 10-16 확인: 50건 |
| 방문자 | **자동** — GA4를 티스토리 플러그인(측정 ID) 또는 스킨 `<head>`에 넣는다 [경험담] → GA4 Data API `activeUsers`, `screenPageViews` [공식]. 티스토리 자체 통계는 API가 없다 (Open API는 2024-02 종료) | **수동** — 블로그 통계 화면. 오픈 API 목록에 통계 항목이 없다 [2차] [네이버 오픈 API 목록](https://naver.github.io/naver-openapi-guide/apilist.html). 스크립트를 못 넣으니 GA4도 설치할 수 없다 [추정] |
| 체류시간 | **자동** — GA4 `userEngagementDuration`, `averageSessionDuration` [공식] [GA4 스키마](https://developers.google.com/analytics/devguides/reporting/data/v1/api-schema) | **수동 또는 불가** — 통계 화면에 시간 항목이 있는지 미확인 |
| 검색 클릭 | **자동** — 서치 콘솔에 블로그마다 **URL 접두어 속성**을 만들고 HTML 태그로 인증 [경험담] → Search Console API `searchAnalytics.query`로 clicks, impressions, ctr, position, 차원 page·query·date [공식] [API](https://developers.google.com/webmaster-tools/v1/searchanalytics/query) | **수동** — 블로그 통계의 유입 경로·검색어. 서치 콘솔은 불가 [추정: 소유권 태그를 넣을 수 없다] |
| 수익 | **자동** — AdSense Management API v2 `reports:generate`, 차원 `DOMAIN_NAME`으로 블로그별 `ESTIMATED_EARNINGS`, `PAGE_VIEWS`, `PAGE_VIEWS_RPM` [공식] [API](https://developers.google.com/adsense/management/metrics-dimensions) | **수동** — 브랜드커넥트 정산 화면. 크리에이터용 API는 없다 [경험담] |

**구글 3종 인증 (한 번만).** 구글 클라우드 프로젝트 하나에서 OAuth 동의를 한 번 받는다. 범위: `webmasters.readonly`, `analytics.readonly`, `adsense.readonly`. **동의 화면이 '테스트' 상태면 갱신 토큰이 7일 뒤 만료된다** → '프로덕션'으로 바꾼 뒤 다시 동의한다 [2차] [Google Health 설정 문서](https://developers.google.com/health/setup).

## 4. 확인하지 못한 것

- **티스토리 하루 발행 15건/50건 원문.** 카카오 고객센터 페이지가 스크립트로 그려져서 본문을 읽지 못했다. 검색 요약만 봤다.
- **`*.tistory.com`을 애드센스에 추가하는 공식 근거.** tistory.com은 PSL에 없고, 애드센스 파트너 목록에 있는지도 모른다. 블로그마다 따로 승인받는 것은 경험담이다. 애드센스 '사이트' 탭에서 직접 확인한다.
- **네이버 하루 발행 상한 공지, 임시저장 300개.** 둘 다 경험담뿐이다.
- **쇼핑커넥트 공식 약관.** 참여 조건(이웃·방문자 기준 폐지), 수수료(직접 3~50%, 간접 1.8%)는 [경험담](https://wplaybook.com/naver-shopping-connect-guide/)이다. brandconnect.naver.com은 이 환경에서 열리지 않는다. 올리브영·무신사가 커넥트에 참여하는지도 모른다.
- **네이버 블로그 통계의 체류시간 항목, 티스토리 RSS 노출 개수 설정의 범위.**
