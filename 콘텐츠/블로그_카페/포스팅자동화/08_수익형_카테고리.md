# 수익형(찍어내기) 계정의 카테고리 — 방향 × 타입

기준: 2026-10-15 한국시간. 사용자가 계정을 둘로 나누기로 했다. **자동화로 찍어내듯 올릴 계정**과 **사용자가 골라서 직접 쓸 계정**이다. 이 문서는 찍어내기 계정에 쓸 카테고리다. 쿠팡파트너스·네이버 쇼핑커넥트로 수익을 낸다.

사용자가 "완벽하다, 기록해 달라"고 한 표다. 아래 표는 그대로 두고, 바꿀 때는 이 문서를 고친다.

## 1. 방향 × 타입

세로 = **사게 만드는 방향 (카테고리)**, 안의 칸 = **글 타입**.

| 카테고리 (사게 만드는 방향) | 타입 | 예시 제목 |
|---|---|---|
| **A. 문제 해결** (불편 → 해결템) | 원인 해설 + 해결 도구 | 겨울마다 정전기 심하면 가습기보다 먼저 볼 것 |
| | 상황별 준비물 | 첫 캠핑, 텐트 말고 먼저 사야 할 6개 |
| **B. 고르기** (살 건 정했는데 뭘 살지 모름) | A vs B | 에어프라이어 바스켓형 vs 오븐형, 1인 가구라면 |
| | ○○한 사람용 추천 | 자취방 좁은 사람용 건조대 |
| | 기준 정리 | 전기요 고를 때 W수보다 먼저 볼 숫자 |
| **C. 타이밍** (언제 사야 싸나) | 시즌 달력 | 11월 세일 달력, 품목별 언제 살까 |
| | 가격 추적 / 행사 정리 | 다이슨 블프 때 평소보다 얼마나 싸졌나 |
| **D. 선물** (누구에게 줄까) | 받는 사람·예산별 | 수능 끝난 조카에게 3만 원 안쪽 |
| | 시즌 선물 | 빼빼로데이 말고 11/11에 줄 만한 것 |
| **E. 비용 계산** (돈 아끼기) | 사는 게 나은지 비교 | 김장, 직접·절임배추·사 먹기 |
| | 유지비·소모품 계산 | 정수기 렌탈 vs 구매, 3년 쓰면 |
| **F. 생활 장면** (따라 하기) | 루틴·세팅 | 퇴근 후 10분 홈트, 쓰는 도구 전부 |
| | 공간 꾸미기 | 원룸 겨울 단열, 3만 원으로 끝내기 |
| **G. 여행·체험** (쇼핑커넥트 전용) | 코스 + 예약 연결 | 11월 단풍 끝물, 남쪽 1박 패키지 고르기 |

## 2. 이 표를 이렇게 짠 이유 (Claude 의 고찰)

### 출발점: 물건이 아니라 "글을 연 사람의 질문"으로 나눴다

처음 떠오르는 분류는 물건 종류(가전·주방·뷰티·육아…)다. 쇼핑몰 카테고리가 그렇게 생겼으니까. 그런데 같은 가습기도 "정전기가 왜 이렇게 심하지"로 들어온 사람, "가열식이냐 초음파냐"로 들어온 사람, "블프 때 얼마나 싸지나"로 들어온 사람은 전혀 다른 글을 원한다. 사게 만드는 힘은 물건보다 **그 사람이 지금 서 있는 자리**에서 나온다.

그래서 해외 제휴 마케팅에서 오래 써 온 구매 여정(문제 인식 → 탐색 → 비교 → 결정 → 사용 후)을 뼈대로 잡고, 단계마다 "독자가 검색창에 치는 질문"이 하나로 모이게 묶었다.

| 구매 여정 단계 | 독자의 질문 | 카테고리 |
|---|---|---|
| 문제 인식 | 이거 왜 이러지, 뭐가 필요하지 | A. 문제 해결 |
| 비교 | 둘 중 뭐가 나한테 맞지 | B. 고르기 |
| 결정 | 지금 사도 되나, 언제가 싸지 | C. 타이밍 |
| 결정 (남을 위해) | 누구에게 뭘 주지 | D. 선물 |
| 결정 (돈 기준) | 사는 게 이득이긴 한가 | E. 비용 계산 |
| 사용 후 · 동경 | 저 사람처럼 하려면 뭐가 있어야 하지 | F. 생활 장면 |

카테고리끼리 겹치지 않게 하는 기준이 이 질문이다. 글 하나를 쓰기 전에 "독자가 이 글을 연 순간의 질문이 무엇인가"를 정하면 카테고리가 하나로 떨어진다.

### 결정 단계를 셋(C·D·E)으로 쪼갠 이유

교과서식 구매 여정에서 '결정'은 한 칸이다. 그런데 한국 블로그 검색에서 실제로 돈이 움직이는 질문은 결정 직전에 셋으로 갈린다. 언제 사나(세일·시즌), 누구 주나(선물), 사는 게 맞나(렌탈·구독·직접 하기와 비교). 셋은 글 모양도 다르다. 타이밍은 달력과 표, 선물은 받는 사람과 예산, 비용은 계산이 중심이다. 한 칸에 두면 틀이 섞인다.

### '후기·리뷰'와 'N가지 추천'을 일부러 뺐다

제휴 글의 대표는 보통 후기와 "BEST 10" 리스트다. 둘 다 이 표에 없다.

- **후기**는 직접 써 봐야 쓸 수 있다. 찍어내기 계정은 경험 재료가 없는 계정이고, 안 써 본 물건을 써 본 것처럼 쓰는 건 [05](05_생성규칙.md) 6절에서 금지했다. 후기는 사용자가 골라서 쓰는 계정의 몫이다.
- **"N가지 추천"**은 [07](07_템플릿화_분석.md)에서 이미 뒤로 미뤘다. 남의 리스트와 똑같아지기 쉽고 판단이 없다. 대신 B의 "○○한 사람용 추천"처럼 **사람을 좁힌 추천**만 남겼다. 사람을 좁히면 글에 판단이 생긴다.

### 타입은 "매번 같은 틀로 다른 물건을 넣을 수 있는가"로 골랐다

찍어내기 계정이니까 타입마다 템플릿이 하나씩 붙어야 한다. 각 타입이 [07](07_템플릿화_분석.md)의 어느 뼈대로 쓰이는지 맞춰 보면 이렇다.

| 타입 | 쓰는 뼈대 (07 4절) |
|---|---|
| A 원인 해설 + 해결 도구 | C. 질문형 해설 |
| A 상황별 준비물 | C 변형 (질문형 소제목 + 준비물 표) |
| B 전부 | B. 비교·고르기형 |
| C 시즌 달력 · 행사 정리 | A. 시즌 달력형 |
| D 선물 | B 변형 (기준 = 받는 사람·예산) |
| E 비용 계산 | B 변형 (비교표에 금액·기간) — T05 김장이 이 모양 |
| F 생활 장면 | 새 뼈대 필요 (장면 → 쓰는 도구 → 대체품) |
| G 여행·체험 | 새 뼈대 필요 (코스 → 예약 상품 비교) |

F와 G는 아직 뼈대가 없다. 시험 원고로 먼저 만들어 본다.

### 예시 제목은 "판단이 들어간 제목"으로 썼다

"에어프라이어 추천"이 아니라 "에어프라이어 바스켓형 vs 오븐형, **1인 가구라면**", "전기요 고를 때 **W수보다 먼저 볼 숫자**"처럼 제목에 이미 조건이나 반전이 들어가게 했다. 사용자가 마음에 들어 한 독감·김장 원고의 공통점이 "정보 나열이 아니라 판단 하나"였기 때문이다. 제목에서 판단이 보이면 같은 품목을 다룬 수많은 글 사이에서 클릭할 이유가 생긴다.

예시 품목은 지금(10월 중순) 쓸 수 있는 것과 시즌이 겹치게 골랐다. 정전기·가습기, 전기요, 블프, 수능, 빼빼로데이, 김장, 단열, 단풍 끝물이다. 표를 보자마자 다음 주 원고 주제로 바로 쓸 수 있게 하려는 것이다.

### G를 따로 둔 이유

다른 카테고리는 물건을 판다. G는 예약을 판다. 2026-08-24 네이버가 '여행 커넥트'를 내면서 쇼핑커넥트(브랜드 커넥트)로 패키지·가이드투어 예약도 수익이 된다 ([머니투데이](https://www.mt.co.kr/tech/2026/08/24/2026082414392288637), 기본 수수료 패키지 3%, 가이드투어 5%). 쿠팡파트너스에는 없는 길이고 네이버 계정에서만 된다. 그래서 플랫폼이 정해진 카테고리로 표 맨 아래에 따로 뒀다. 사용자가 말한 "커넥트는 물건에 국한되지 않는다"가 여기에 해당한다.

## 3. 함께 정한 것 (같은 날 대화, 요약)

- **잘 팔리는 물건 성향:** 소모품·재구매, 1~5만 원 충동 구간, 옵션이 많아 고르기 피곤한 것, 시즌이 정해진 것, 고단가 저빈도(수수료율은 낮아도 건당 금액이 큼).
- **플랫폼 짝:** 네이버 찍어내기 계정 = 쇼핑커넥트 (A·B·D·G), 티스토리 = 쿠팡파트너스 + 애드센스 (B·C·E). 쿠팡 링크가 네이버에서 노출이 떨어진다는 건 공식 기준이 없는 경험담이다.
- **추천 뼈대:** 찍어내기 계정은 B(고르기)와 C(타이밍)를 중심에 두고, 소모품·시즌 품목을 돌려 쓴다. 틀이 같아도 품목과 날짜가 바뀌어 겹치지 않는다.
- **수수료 수치**(쿠팡 약 1~3%, 쇼핑커넥트 상품별 약 5~30%)는 블로그 정리 수준이다. 실제 값은 각 파트너 센터에서 확인한다.

## 4. 다음에 할 것

1. 카테고리를 원고 데이터에 붙인다 (`카테고리 A~G` + `타입`). [07](07_템플릿화_분석.md) 7절의 "형식을 데이터로 둔다"와 같이 간다.
2. 뼈대가 없는 F(생활 장면)와 G(여행·체험)를 시험 원고로 한 편씩 써 본다.
3. 같은 카테고리가 3편 연속 나오지 않게 아침 주제 카드를 섞는다 (07 7절 4번).
