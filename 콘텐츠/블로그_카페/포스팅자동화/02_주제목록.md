4. 장르와 중심 관찰을 정하고, 기존 글과 다른 이유가 있는지 확인한다.
5. 실제 정보가 변한 소재는 집필 전에 다시 확인한다. 날짜만 최신으로 바꾼 글을 만들지 않는다.

현재 외부 플랫폼 신호의 새 검증은 접근 제한으로 남아 있다. 기존 기록 신호, 달력의 계절성, 새 관점의 가설을 섞어 “지금 급상승한 36개”라고 표현하지 않는다.

## 반복 제작의 방향

초기에는 다양한 장르를 시험하되 한 카테고리의 독자 기대를 유지한다. 예를 들면:

`다이어리 선택(C01) → 기록 구조 설명(D01) → 실제 일주일 후기(F02) → 빈 페이지 고찰(E05)`

`카페 이용 조건(B02) → 실제 방문 일상(A형) → 재방문 평가(F05) → 동네 코스 안내(B06)`

`AI 원고의 관점(E02) → 실제 손질 기록(F01) → 이미지 역할 해설(D02)`

후기·실험은 실제 재료가 생겼을 때 이어 간다. 일정에 맞추려고 경험·성과·독자 반응을 지어내지 않는다. 하루 글을 준비하는 과정에서 나온 새 질문은 다음 후보로 축적한다.
