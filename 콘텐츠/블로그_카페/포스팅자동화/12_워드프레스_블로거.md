# 워드프레스 · 블로거를 더할까

조사: 2026-10-16 (한국시간), Claude. 확인일은 모두 10-16. 등급은 [10](10_플랫폼별_자동화_위험.md)과 같다: [공식] · [2차 보도] · [경험담] · [추정]. 구글 스팸·애드센스 정책은 [10](10_플랫폼별_자동화_위험.md) 3절에 있으니 되풀이하지 않는다.

## 1. 결론

- **둘 다 공식 API로 '임시저장'까지 올릴 수 있다.** 티스토리·네이버와 달리 복사·붙여넣기 단계가 사라진다. 이게 유일하게 큰 장점이다 [공식].
- **한국 검색 유입은 티스토리보다 약하다.** 네이버에서는 블로그 탭이 아닌 웹문서 쪽으로 간다는 경험담이 대부분이다 [경험담]. 구글 유입이 주력이어야 한다.
- **먼저 더한다면 블로거.** 무료, 애드센스가 메뉴에 붙어 있고, 조회수 API도 있다. 다만 2020년 이후 공식 업데이트 소식이 없다 [공식].
- 용도는 **구글 검색 위주 주제**(정답형 정보 글, 영어 글)로 시작. **하루 1편**, 애드센스 승인 전에는 주 4~5편. 플랫폼이 달라도 구글 '확장된 콘텐츠 악용'은 똑같이 적용된다 [공식].
- 워드프레스는 **수익이 확인된 뒤** 설치형으로. 처음부터는 비용·관리 부담이 크다 [추정].

### 공통

- **API로 임시저장하는 것 자체는 정상 사용**이다. 두 플랫폼 모두 공식 기능이고, 매크로처럼 화면을 흉내 내지 않는다 [공식 기능 + 추정]. 그래도 구글은 만든 방법이 아니라 **결과**(가치 없는 대량)를 본다 [공식, [10](10_플랫폼별_자동화_위험.md) 3-1].
- **새 도메인의 불리함**: 글 30편 정도의 새 사이트는 적게 크롤링된다는 뮬러 발언 [2차, [10](10_플랫폼별_자동화_위험.md) 3-3]. 애드센스 사이트 검토는 보통 며칠, 길면 2~4주 [공식] [애드센스](https://support.google.com/adsense/answer/12169212?hl=en).
- **쇼핑커넥트 링크**: 보도에는 "네이버 블로그, 인스타그램 등" 채널만 예시. 블로거·워드프레스 허용 여부는 미확인 [2차 보도] [헤럴드경제](https://www.heraldk.com/article/2025072218190389988).

## 4. 우리 파이프라인에 붙이는 법

1. **연결 1회**: 블로거는 구글 OAuth(권한 `blogger`), 워드프레스는 애플리케이션 비밀번호를 서버 `.env`에 저장.
2. **'임시저장 보내기' 버튼**: 손질 전 원고를 HTML로 바꿔 블로거 `isDraft=true` / 워드프레스 `status=draft`로 올린다. 이미지는 워드프레스는 media 업로드, 블로거는 외부 주소(방식 미정).
3. **사용자 손질·발행**: 플랫폼 에디터에서 [10](10_플랫폼별_자동화_위험.md) 5절 3번 다섯 가지 손질 후 직접 발행. **자동 발행·자동 예약은 쓰지 않는다** (손질 단계를 지키기 위해) [추정].
4. **겹침 검사 그대로**: 지금 복사 버튼 앞에 있는 자기 글 겹침 검사를 '보내기' 앞에 둔다 ([07](07_템플릿화_분석.md) 7절).
5. **통계 회수**: 블로거 `pageviews`(30일)를 하루 한 번 가져와 글 목록 옆에 표시. 글별 수치는 GA4·서치 콘솔에서.

## 5. 확인하지 못한 것

- **블로거 API 공식 할당량**(글 생성 하루 한도). 50건은 경험담뿐. 구글 클라우드 콘솔에서 직접 봐야 한다.
- **블로거 API 이미지 업로드** 공식 방법.
- **블로거 애드센스 '수입' 메뉴가 열리는 조건**(편수·기간). 공식 기준 없음.
- **WP.com 애드센스 허용 요금제 공식 문서.** 직원 포럼 답변만 확인. 요금표에는 이제 플러그인이 유료 전 요금제로 바뀌어 있어, Personal·Premium에서도 될 수 있다 [추정].
- **국내 호스팅(카페24 등) 2026년 워드프레스 요금**, 도메인 원화 가격.
- **네이버 서치어드바이저·다음 웹마스터도구 공식 안내 원문.** 이 환경에서 열리지 않았다. 외부 블로그가 네이버 블로그 탭에 나오는지 현재 기준은 경험담뿐.
- **쿠팡파트너스·쇼핑커넥트의 블로거·워드프레스 채널 허용** 원문.
- 블로거·워드프레스에서 **실제 한국어 글 유입량** 자료. 없다. 4주 시험 운영으로 잰다.
