# 트렌드 신호 — 2026년 10월 중순

조사: 2026-10-15 (한국시간), Claude. 출처 6곳(네이버 · 다음 · 구글/티스토리 · 유튜브 · 인스타그램 · 틱톡)은 **같은 순위**로 본다.

> **확인 수준.** 6곳 모두 이 환경에서 직접 접속이 막혔다. 아래 신호는 그 플랫폼의 데이터를 인용한 기사, 제3자 집계 사이트, 공식 문서를 **웹 검색 발췌로** 확인한 것이다. 원문을 열어 대조하지 않았다. 숫자는 발췌에 나온 그대로이며, 기준(전년 대비·전주 대비)이 서로 달라 비교할 수 없다. 글을 쓰기 직전에 다시 확인한다 ([04 구조](04_자동화구조.md)의 '사실 재확인' 단계).

## 1. 출처별로 자동 수집이 되는가

순위는 같다. 하지만 **매일 기계로 모을 수 있는 정도가 다르다.** 자동화는 이 차이를 받아들이고, 막힌 곳은 사용자의 짧은 메모로 채운다.

| 출처 | 수집 방법 | 자동화 | 2026년 상태 | 근거 |
|---|---|---|---|---|
| 구글 | "지금 뜨는 검색어" RSS `trends.google.com/trending/rss?geo=KR` (비공식, 문서 없음) | ○ (실측 필요) | 공식 Trends API는 2025-07 발표, 신청자만 쓰는 알파. `pytrends`는 2025-04-17 보관(중단) | [Trends API 발표](https://developers.google.com/search/blog/2025/07/trends-api), [pytrends](https://github.com/GeneralMills/pytrends) |
| 네이버 | 데이터랩 검색어 트렌드(키워드를 **미리 넣어야** 상대지수가 나옴. 급상승 목록은 없음) + 검색 API(블로그·뉴스 문서 수) + 검색광고 API(연관 키워드·월 검색수) | ○ | **오픈API가 'NAVER API HUB'(네이버클라우드)로 이관.** 신규 키는 HUB에서만 발급(2026-07-31부터), 기존 키는 2027-06-30 종료. 쇼핑 검색 API는 종료 | [API HUB 개요](https://guide.ncloud-docs.com/docs/apihub-overview), [검색광고 API](https://github.com/naver/searchad-apidoc) (2차 자료 포함) |
| 다음 | 카카오 검색 API(웹·블로그·카페·영상) — 키워드 검색만 가능 | △ (문서 수·최신 글 확인용) | 다음 '실시간 트렌드' 베타(2026-03)는 화면만 있고 API는 없음. 다음 검색 점유율 2%대 | [카카오 검색 API](https://developers.kakao.com/docs/latest/ko/daum-search/dev-guide), [다음 실시간 트렌드 소개](https://brunch.co.kr/@daum/32) |
| 유튜브 | YouTube Data API `videos.list?chart=mostPopular&regionCode=KR` | △ | **2025-07-21부터 '인기 급상승' 폐지.** mostPopular는 음악·영화·게임 차트 기반이 되어 신호로서 약해짐 | [API 변경 이력](https://developers.google.com/youtube/v3/revision_history) |
| 인스타그램 | Graph API 해시태그 검색 — 해시태그를 **미리 알아야** 하고 7일에 30개까지. 비즈니스 계정·앱 심사 필요 | △ | 인기 해시태그 목록 API 없음 | [해시태그 검색 문서](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-facebook-login/hashtag-search) |
| 틱톡 | Creative Center 인기 해시태그 — **공식 API 없음.** Research API는 미국·유럽 학술 연구자 전용 | × | 스크래핑은 약관 위험 | [Research API](https://developers.tiktok.com/products/research-api/) |

**결론:** 구글 RSS + 네이버(HUB 검색·데이터랩·검색광고)로 매일 자동 수집한다. 다음·유튜브는 보조로 쓴다. 인스타·틱톡은 사용자가 폰으로 본 것을 한 줄씩 적는 **수동 메모 칸**으로 받는다. 수동 메모도 자동 수집과 같은 무게로 점수에 들어간다.
