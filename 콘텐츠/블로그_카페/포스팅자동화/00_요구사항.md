# 포스팅 자동화 — 사용자 요구 확정

기준: 2026-10-15 한국시간, 사용자 정정. **사용자가 글을 잘 쓰도록 안내하는 도구가 아니라, AI가 매일 게시할 만한 글을 만들어 주는 도구다.**

## 사용자 원문에서 고정할 뜻

> “너가 ai스럽지않게 어떤 주제에도 … 사람이 쓴 것 처럼 적절한 이미지, 멘트, 이모티콘 등을 배치해서 글을 작성하면 내가 조금이라도 다듬고 끝내는 그 자동화템플릿”
>
> “스토리텔링식 마치 브이로그같은 일상 … 맛집이나 무언가에 대해 소개 안내 … 어떤 주제에 설명 또는 고찰 … 피드백 평가”
>
> “매일 양질의 포스팅을 하기 위한 자동화도구 … 저런 가이드 전혀 필요없어”

## 목표 결과물

주제에 맞는 **거의 완성된 포스팅 한 편**. 사용자는 읽어 보고 자기 취향·경험과 다른 부분만 조금 다듬고 게시한다.

- 제목, 자연스러운 도입, 장르에 맞는 전개, 구체적인 관점, 과하지 않은 마무리.
- 이미지의 종류·위치·순서·역할, 사진 아래 멘트, 필요한 비교표·도식.
- 말투, 문단 길이와 호흡, 적절한 이모티콘과 작은 농담까지 본문에 함께 반영.
- 자료 확인과 사실 검수도 AI의 제작 과정 안에서 처리. 사용자에게 모든 문장을 다시 쓰게 하지 않는다.
- 일상·방문·사용기는 사용자의 실제 메모·사진을 재료로 완성한다. AI가 안 간 식당을 다녀왔다고 쓰거나 안 먹은 맛을 경험담으로 만들지 않는다. 경험 재료가 없으면 자료 기반 소개·비교·고찰 형식으로 완성한다.
- 이미지 계획만 있는 결과와 실제 이미지까지 준비된 결과는 구분한다. 생성 그림을 실제 매장·음식·사용 증거 사진으로 대신하지 않는다.

## 필요한 장르

| 장르 | 독자가 따라가는 흐름 | AI가 완성할 부분 |
|---|---|---|
| 일상·브이로그·스토리텔링 | 작은 장면 → 선택·변화 → 여운 | 시간 흐름, 장면 전환, 사진과 짧은 멘트, 담백한 감정 |
| 맛집·공간·제품 소개·안내 | 궁금한 포인트 → 선택에 필요한 정보 → 누구에게 맞는지 | 분위기·특징·조건·동선·가격의 확인, 이미지 순서, 유용한 팁 |
| 설명·해설 | 익숙한 의문 → 이해되는 사례 → 원리·예외 | 쉬운 비유, 비교 그림, 단계별 설명, 정확한 근거 |
| 고찰·에세이 | 관찰 → 생각이 바뀌는 지점 → 자기 입장 | 구체적인 문제, 반대 관점, 과장하지 않는 결론 |
| 후기·평가·피드백 | 기대·기준 → 관찰·결과 → 좋음·아쉬움·맞는 사람 | 조건이 드러나는 평가, 실제 사례, 장단점의 균형 |

하나의 고정된 서론·본론·결론에 모든 글을 끼워 넣지 않는다. 주제와 재료에 따라 장르를 섞을 수 있어야 한다.

## 사용 흐름의 원칙

1. 주제만 주거나, 기존 후보에서 선택한다. 사진·경험이 있으면 짧게 덧붙인다.
2. AI가 필요한 조사, 장르 선택, 구성, 집필, 이미지 구성, 퇴고를 맡는다.
3. 사용자는 완성된 글을 먼저 본다. 바꾸고 싶은 부분만 짧게 지시한다.
4. 티스토리에 옮겨 마무리할 수 있는 본문과 이미지 묶음을 준비한다.

사용자에게 독자·핵심 질문·정답·소제목·출처·모든 본문을 단계마다 직접 적게 하는 흐름은 목표에서 벗어난다. 설정과 분석은 뒤에서 작동하고, 화면은 직관적으로 유지한다.

## 분석과 설계의 기준

- 실제 인기·유명 글의 **내용**을 읽고 도입, 전개, 관점, 이미지, 멘트, 이모티콘, 마무리를 분석한다. 도구 설명서만 조사하고 글 분석을 했다고 하지 않는다.
- 조회·반응·외부 추천 등의 근거와 필자의 평판을 구분한다. 유명 필자의 모든 글이 인기 글은 아니다.
- 원문 표현과 특정 필자의 고유한 목소리를 복제하지 않는다. 효과가 있는 구성 원리를 여러 사례에서 뽑아 우리 콘텐츠의 관점으로 새로 쓴다.
- 현재 트렌드의 근거와 계절성·장기 수요·미검증 가설을 구분해 주제를 제안한다.
- 트렌드 출처는 모두 같은 순위: 네이버, 다음, 구글(티스토리), 유튜브, 인스타그램, 틱톡.
- 핵심 성과는 **수정량이 적으면서 읽을 만한 완성 글을 반복 생산하는 것**이다. 생성 수·글자 수·검색 점수만 성과로 삼지 않는다.
