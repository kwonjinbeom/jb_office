# 일일 아이디어 루틴

안내문의 날짜·하루 양만큼 아이디어 후보를 찾는다.

## 먼저 읽기
- AGENTS.md
- 시장조사/00_아이디어_조사방법.md

## 할 일
1. 안내문 '오늘의 자료 › 검색 표준'(최신판)에 맞춰 조사한다. 표준과 다르게 판단한 부분은 상세 문서 맨 위에 이유와 함께 적는다.
2. '오늘의 자료 › 지난 후보'와 겹치지 않게 한다. 로컬이면 시장조사/일일아이디어/*.json 도 직접 확인한다.
3. 결과 형식은 검색 표준의 요청문을 따른다 (날짜.json + 상세 조사 문서).
4. 끝나면 main 에 커밋·push 한다 (서버 반영은 웹훅이 자동).
