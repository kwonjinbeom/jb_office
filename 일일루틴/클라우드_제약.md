# 클라우드 세션 제약

클라우드 세션(저장소만 있고 PC 브라우저·DB 가 없는 곳)에서 루틴을 돌릴 때 루틴 프롬프트와 함께 지킨다.

- 티스토리·네이버·블로거 같은 블로그는 열지 않는다. 막히거나 제대로 안 보인다. 겹침은 안내문의 '오늘의 자료 › 이미 있는 글'로 피한다.
- 웹 검색은 막힌 곳이 많다. 막힌 출처는 결과 문서나 원고 제작 정보에 `확인 못 함: <주소>` 로 적고 넘어간다. 확인 못 한 숫자는 쓰지 않는다.
- 진행 보고 명령(`routine_report`)은 쓰지 않는다. PC 의 DB 가 없다.
- main 에 바로 push 하지 않는다. 새 브랜치에 커밋하고 main 으로 PR 을 만든다.
