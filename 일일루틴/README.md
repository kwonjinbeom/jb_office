# 일일루틴

일일루틴 화면(`/routines/`)이 AI 에게 맡기는 일의 프롬프트. 화면은 실행할 때 짧은 안내문만 만들고, 실제 지시는 여기 md 를 읽게 한다.

- `프롬프트/<루틴 키>.md` — 루틴마다 하나. 화면의 '실행'·'전체 실행'·'추가 실행'이 같은 파일을 본다.
- 모두 PC 에서 손으로 돌린다. 일일루틴 › 글쓰기 자동화의 '전체 실행'은 글쓰기를 새 터미널에서 돌린다.
- '여러 날'은 고른 날마다 그 날짜의 글쓰기를 새 터미널에서 차례로 돌린다 (며칠치 미리 쓰기). 결과·횟수는 그 날짜에 남는다.
- '변환까지'를 체크하고 실행하면 글쓰기 터미널이 끝난 뒤 차례 창이 서버에서 그날 쓴 글을 발행예정글(예정일 그날)로 옮기고, 받은 변환 안내문으로 변환 터미널을 이어서 연다 (`manage.py routine_convert`).
- 일일 아이디어·프롬프트 최신화는 전체 실행에서 뺐다 (2026-10-31). 일일루틴 › 수동 루틴의 탭(아이디어 찾기 · 프롬프트 최신화)에서 손으로 돌린다.
- 진행 상황은 서버의 일일루틴 실행 이력에 남는다 (설정 › 일일루틴 실행 보고 토큰). 결과는 main 에 올라가고 웹훅이 서버에 반영한다.
- 프롬프트는 **프롬프트 최신화** 루틴으로 고친다. 수동 루틴 › 프롬프트 최신화 탭의 '실행'으로 일주일에 한두 번 돌리고, 브라우저로 블로그·트렌드를 깊게 조사해 각 프롬프트에 쌓는다 (`프롬프트/prompt_update.md`). 며칠 건너뛰어도 루틴은 계속 돈다.
- 바뀐 내용은 프롬프트 관리의 이력에 쌓인다 (git 기록도 남는다).
