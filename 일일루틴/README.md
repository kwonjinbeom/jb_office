# 일일루틴

일일루틴 화면(`/routines/`)이 AI 에게 맡기는 일의 프롬프트. 화면은 실행할 때 짧은 안내문만 만들고, 실제 지시는 여기 md 를 읽게 한다.

- `프롬프트/<루틴 키>.md` — 루틴마다 하나. 예약 실행과 화면의 '실행'이 같은 파일을 본다. 로컬·클라우드 구분은 없다.
- **매일 아침 7시 예약 실행**: 일일 아이디어·글쓰기는 claude.ai 의 클라우드 루틴이 돈다. 서버의 예약 실행 주소(설정 › 일일루틴 예약 실행 주소)에서 그날 안내문을 받아 그대로 하고, 결과를 main 에 올린다. 웹훅이 서버에 반영한다.
- 화면의 '실행'은 더 하고 싶을 때 PC 터미널로 한 번 더 돌리는 것이다.
- 프롬프트는 **프롬프트 최신화** 루틴으로 고친다. PC 에서 '실행'으로 돌리고, 브라우저로 블로그·트렌드를 깊게 조사해 각 프롬프트에 쌓는다 (`프롬프트/prompt_update.md`). 며칠 건너뛰어도 루틴은 계속 돈다.
- 바뀐 내용은 프롬프트 관리의 이력에 쌓인다 (git 기록도 남는다).
