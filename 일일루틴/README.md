# 일일루틴

일일루틴 화면(`/routines/`)이 AI 에게 맡기는 일의 프롬프트. 화면은 실행할 때 짧은 안내문만 만들고, 실제 지시는 여기 md 를 읽게 한다.

- `프롬프트/<루틴 키>.md` — 루틴마다 하나. 로컬·클라우드가 같은 파일을 본다.
- `클라우드_제약.md` — 클라우드 세션일 때만 함께 읽는다 (인터넷·사이트 제한).
- 프롬프트는 일일루틴 리스트의 **프롬프트 최신화** 루틴으로 고친다: 프롬프트 관리에 남긴 평가(평점·코멘트)와 루틴별 점검 관점을 반영해 AI 가 고치고 main 에 올린다 (`프롬프트/prompt_update.md`).
- 바뀐 내용은 프롬프트 관리의 이력에 쌓인다 (git 기록도 남는다).
