# 일일 아이디어 운영 방식

> 매일 아이디어를 함께 검토해 '일일 아이디어' 화면에 쌓는다. 화면은 **한눈에 훑고 검토**할 수 있어야 하고, 무엇을 어떻게 찾을지는 사용자가 쓰는 **검색 표준**이 정한다.

## 1. 지금까지 정한 것

| 항목 | 정한 내용 | 정한 날 |
|---|---|---|
| 화면 | 위쪽 달력 띠(← → 키, 날짜 고르기), 목록은 **아이디어 · 세부내용** 두 칸, 누르면 구현 계획과 검토 근거가 펼쳐짐 | 10-14 |
| 기존 36개 | Codex가 10-13 밤에 만든 조사라 **10-13** 으로 옮김 (번호 `20261013-01`~`36`) | 10-14 |
| 내 아이디어 | 시장조사 문서에서 일괄로 넣었던 35개를 지움. 앞으로 **사용자가 직접 담은 것만** | 10-14 |
| 검색 표준 | 8개 항목을 서버 화면에서 사용자가 쓰고, 저장할 때마다 버전(v1, v2 …)이 남음 | 10-14 |
| 제외할 것 | 후원·팁 구조, 단순 재업로드, 이전 후보 반복은 **제외하지 않음** (사용자가 표준에서 지움) | 10-14 |
| 출처 | 네이버 · 다음 · 구글(티스토리) · 유튜브 · 인스타그램 · 틱톡 — **모두 같은 순위** | 10-14 |
| 요청 방식 | 요청문을 복사하지 않음. "아이디어 찾아줘" 하면 Claude가 서버의 **최신 표준을 직접 읽고** 시작 | 10-14 |

## 3. 출처별 접근 상태 (10-14 이 PC에서 확인)

| 출처 | 상태 | 볼 수 있는 것 | 열려면 |
|---|---|---|---|
| 구글 트렌드 | ✅ 열림 | 한국 실시간 인기 검색어, 검색량, 상승률, 관련어 | — |
| 유튜브 | ✅ 열림 | 검색 · 최신순 · 조회수 · 올린 시기 · 설명 | — |
| 다음 · 티스토리 | ✅ 열림 | 블로그 · 카페 검색, 쇼핑 광고(팔리는 상품 신호) | — |
| 틱톡 | △ 일부 | 크리에이티브 센터 해시태그 순위 상위 3개 | 크롬 확장 + 로그인 |
| 인스타그램 | ❌ | 로그인 화면으로 넘어감 | 크롬 확장 + 로그인 |
| 네이버 | ❌ | 앱 내장 브라우저·웹 가져오기 모두 차단 | 크롬 확장 |

크롬 확장(Claude in Chrome)은 사용자의 크롬을 로그인된 상태 그대로 쓴다. 비밀번호는 사용자가 직접 입력한다. 같은 확장으로 서버의 검색 표준도 읽는다.

**한계**
- 표본 관찰이다. 하루 수십 페이지를 사람처럼 훑는 수준이지 전체 데이터가 아니다.
- 네이버 데이터랩은 상대 지수만 보여 준다. 정확한 검색량은 검색광고 계정이 있어야 한다.
- 인스타·틱톡 피드는 계정마다 다르게 보여서, 태그 검색과 순위 페이지 위주로 본다.

## 4. 아직 논의할 것

1. **하루 몇 개가 검토하기 좋은가** — 표준은 "30개 안팎, 먼저 볼 10개"다. 실제로 검토해 보고 조정한다.
2. **트렌드의 신선도** — "최근 며칠 안의 신호"처럼 기간 기준을 표준에 넣을지.
3. **검토 결과 표시** — 지금은 '내 아이디어에 담기'만 있다. '보류 / 버림'도 남길지.
4. **중구분** — 사용자가 나중에 정한다.
