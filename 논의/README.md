# 논의

'논의 현황'(각 메뉴 아래)과 '진행현황'(전체)에 올라가는 정리 글. Claude·Codex 가 대화를 정리해 md 로 쓰고 push 하면,
서버가 화면을 열 때 이 폴더를 읽어 **목록에는 한 줄 제목**, **들어가면 이 글**로 보여 준다.

- 폴더: `논의/<대구분>/YYYY-MM-DD_제목.md` — 대구분 폴더는 `일일아이디어`, `내아이디어`, `블로그_카페`, `영상콘텐츠`
- 파일 하나 = 논의 하나. 경로가 이름표라 옮기거나 이름을 바꾸면 새 논의가 된다. 같은 논의는 같은 파일을 고쳐 쓴다.
- 맨 위 앞머리(제목·대구분·중구분·상태·핵심·다음 행동·대화 상대·대화량·등록·날짜) 형식과 규칙은
  `workspace/apps/discussions/docs.py` 머리말에 있다. 제목은 한 줄로 짧게.
- 본문은 Markdown. 표, 이미지(글 옆에 두고 상대 경로), 그리고 `<div>` 로 감싼 `<svg>` 그림·그래프도 그대로 보인다.
- 글을 고치면 앞머리 값이 화면에서 고친 상태·핵심·다음 행동을 덮는다.
- 이 README 와 `_` 로 시작하는 파일은 논의로 올라가지 않는다.
