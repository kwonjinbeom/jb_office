# 티스토리 글쓰기 도우미

메뉴: **블로그·카페 → 티스토리 글쓰기**.

| 공간 | 하는 일 |
|---|---|
| 내 원고 | 기획·자료 → 본문 작성 → 검수 → 티스토리에 옮기기 |
| 템플릿 | 해결·비교·경험·큐레이션·소식·칼럼·FAQ·체크리스트, 내 틀 저장 |
| 작성 설정 | 카테고리별 독자·말투·마무리·제휴 표시, 선택적 AI 연결 |

- 자동 저장, 탭별 복구 자료, 최근 30개 버전, JSON 백업·가져오기.
- 기존 블로그·카페 원고와 연결. 게시 URL·날짜도 기존 기록에 반영.
- 기본모드용 서식 복사·HTML모드용 코드 복사, 제목·태그 별도 복사.
- AI는 API 키 설정 후 초안 생성. 설정 없이도 글 틀·AI 요청문·검수·복사 사용 가능.

다음은 실제 글 한 편으로 원고의 내용과 작성 규칙을 다듬는 일이다.

개발 안내: `workspace/TISTORY_WRITER.md`. 실제 티스토리 게시와 이미지 업로드는 편집기에서 마무리한다.
