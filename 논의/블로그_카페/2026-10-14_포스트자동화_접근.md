# 블로그·카페 포스트 자동화 접근

**추천:** 독자와 반복해서 답할 질문을 정하고, 형식별 템플릿으로 꾸준히 제작한다. AI는 자료·초안·편집을, 사람은 사실 확인과 핵심 판단을 맡는다.

| 구분 | 먼저 잡을 것 |
|---|---|
| 블로그 | 검색 질문에 답하는 해결·비교·경험 글 |
| 카페 | 모임 맥락에 맞는 짧은 정보·사례·구체적인 질문 |
| 수익 | 광고 / 제휴 / 자체 파일·도구 / 반복 자료·구독을 비교 |
| 자동화 | 소재·출처 → 템플릿 초안 → 검수 → 게시 준비·예약 → 반응·갱신 |

## 가져올 만한 것

- **TYPO3 편집 지침:** 글 구성, 문체, 사실·AI 검수, 게시 흐름이 정리돼 있다.
- **Hugo 템플릿·n8n:** 형식별 원고 생성과 RSS·예약·WordPress 연결을 조합할 수 있다.
- **WordPress·Blogger·Ghost:** 게시 API 확인. 국내 블로그·카페 자동 게시 허용 범위는 미확인.
- **Google Site Kit·Yoast:** 유입·수익 측정과 원고·기술 설정 점검. 도구 자체가 수익을 보장하지는 않는다.

## 글 틀

해결형 `상황 → 답 → 단계 → 예외` · 비교형 `독자 → 기준 → 표 → 조건별 선택` · 경험형 `과정 → 결과 → 실패·배움` · 카페형 `상황 → 짧은 정보 → 구체적 질문`.

## 다음

독자층 1개와 템플릿 2개로 소량 제작해 수정 부담·독자 반응부터 확인한다. 첫 주제·게시처·수익 경로는 아직 결정하지 않았다.

이번에는 공개 공식 문서·도구 자료를 분석했다. 구글·다음·국내 플랫폼 등은 직접 접근이 차단돼 최신 정책·실제 수익 사례를 확인하지 못했다. 채널 개설·자동 게시·개발은 하지 않았다.
