# 네이버 글쓰기

블로그·카페 → **네이버 글쓰기** (`/blog/naver-writing/`).

티스토리의 임시 템플릿·검토 템플릿·포스트 관리 화면과 같은 목록, 검색, 상태, 개별/일괄 이동,
발행일 자동 입력, 발행 완료 시 되돌리기 제한, 위·아래 글 이동, 제목·본문·태그 복사를 제공한다.
`apps/naver_writing.Post`에 별도로 저장한다. 기존 티스토리 원고를 바꾸거나 자동 복제하지 않는다.

## 실제 편집기 관찰 (2026-10-15)

사용자가 내장 브라우저에서 직접 네이버 로그인 후, 블로그 홈 → 글쓰기로 들어가
SmartEditor ONE의 작성 화면과 메뉴를 확인했다. 시험용 본문 붙여넣기는 확인 뒤 실행 취소했고,
네이버의 저장·발행 버튼은 누르지 않았다.

- 상단은 첨부 도구, 그 아래는 문단·서체·크기·굵게/기울임/밑줄/취소선·색·정렬·줄간격·목록·첨자 순서.
- 기본은 **나눔고딕 15px, 줄간격 180%**, 제목은 32px. 제목 아래 얇은 선과 여백을 둔 흰 문서.
- 문단 메뉴는 본문·소제목·인용구. 크기는 11/13/15/16/19/24/28/30/34/38,
  줄간격은 150~210%를 제공한다.
- 인용구 6종(따옴표·버티컬 라인·말풍선·라인&따옴표·포스트잇·프레임), 구분선 8종,
  PC/모바일 문서 폭 전환을 확인했다. 이 도구에서는 인용구·구분선 모양을 안전한 HTML로 구현했다.
- 글 보기는 네이버 공개 글의 카테고리 → 제목 → 날짜 → 본문 → 태그 순서를 참고했다.

## 작성·미리보기

- 새 템플릿과 수정 모두 네이버 전용 편집기를 사용한다 (`static/js/naver-editor.js`).
- 글꼴 5종: 나눔고딕·나눔명조·나눔바른고딕·나눔스퀘어·마루부리.
  네이버 한글한글 아름답게의 공개 웹폰트를 불러오고 시스템 폰트를 예비로 쓴다.
- 글자 크기/색/배경색, 문단 정렬/줄간격, 굵게·기울임·밑줄·취소선, 목록, 위·아래첨자,
  특수문자, 인용구 6종, 구분선 8종, 링크, 코드, 행·열을 지정하는 표와 행·열 추가/삭제.
- 사진은 JPG/PNG/WEBP를 문서 안에 넣는다. 장당 최대 10MB 입력, 긴 변 1600px 이하 JPEG로 변환.
  저장 본문은 최대 2MB. 이미지 주소와 기존 티스토리 방식의 사진/그림 자리도 쓸 수 있다.
- 마크다운 붙여넣기는 서버에서 HTML로 바꾼다. 외부 HTML은 허용 태그와 서식만 남긴다.
- 미리보기는 저장 전 내용을 서버에서 검증해 PC·모바일 폭으로 보여 준다.
- 실행 취소/다시 실행(40단계), Ctrl+S 저장, 미저장 이탈 확인, 글자 수(사진 자리 제외).

## 네이버 붙여넣기 실측과 차이

샘플 원고를 실제 네이버 편집기에 붙여넣어 **소제목 24px·나눔명조 24px·굵게·가운데 정렬·표의 행/열**을 확인했다.
외부 CSS는 복사되지 않으므로 `paste_html`이 글자 크기·줄간격을 인라인으로 명시하고,
영문 웹폰트 이름을 네이버가 인식하는 한글 글꼴 이름으로 바꾼다.

네이버는 붙여넣은 인용구를 네이버 인용 컴포넌트로, 점선 사진 자리 상자를 1칸 표로 재해석할 수 있다.
이 도구의 보기와 네이버의 최종 발행 모양이 모든 요소에서 완전히 같지는 않다.
사진 자리에는 실제 사진을 올리고 자리 상자를 지우면 된다. 사진 자체의 클립보드 재업로드는 보장하지 않으므로
실제 발행 사진은 네이버에서 첨부한다.

MYBOX·스티커·동영상 업로드·장소·내돈내산·라이브러리·맞춤법 같은 네이버 계정/서비스 기능은 연결하지 않았다.
편집과 원고 관리 도구이며, 네이버 자동 발행 기능은 없다.

## 배포·검증

- migration `naver_writing/0001_initial`: 새 원고 표 **하나만 추가**. 기존 데이터 변경·삭제 없음.
- 병합하면 서버에 자동 migrate 됨. PC 개발 DB를 직접 변경하지 않는다.
- 시스템 검사, migration 소스 일치, 네이버/티스토리 데이터 분리와 상태 전이·서식 보존·HTML 안전성 테스트.
- 임시 DB의 로컬 서버에서 목록·작성·상세·수정·모바일 미리보기·복사와 실제 네이버 붙여넣기를 확인한다.
