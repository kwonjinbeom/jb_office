# 티스토리 글쓰기

메뉴: **블로그·카페 → 티스토리 글쓰기** (`/blog/writing/`, 앱 `apps/writing`).

2026-10-15 사용자 지시로 예전 구성(내 원고·템플릿·작성 설정, AI 초안·검수·내보내기)과 그 데이터를 모두 지우고, 글 한 편이 세 화면을 옮겨 다니는 구조로 바꿨다.

## 세 화면

| 화면 | 주소 | 들어 있는 것 | 상태 칸 |
|---|---|---|---|
| 임시 템플릿 | `/blog/writing/` | 일단 뽑아 둔 템플릿 | 없음 |
| 검토 템플릿 | `/blog/writing/review/` | 쓸지 따져 보고 손보는 템플릿 | 검토: 미검토 · 검토 중 · 검토 완료 |
| 포스트 관리 | `/blog/writing/posts/` | 실제로 쓰고 발행할 글 | 작성: 미작성 · 작성 중 · 작성 완료 / 발행: 미발행 · 발행 완료 |

- 이름 규칙: **[정해진 정도] + [대상]**. 화면을 늘릴 때도 같은 규칙을 따른다 (예: 보관 템플릿).
- 목록 칸: 제목 · 내용(요약, 없으면 본문 앞부분) · 화면별 상태 · 만든 날(임시) / 수정일(검토·포스트) · 이동 버튼.

## 옮기기 규칙

- 한 칸씩만 옮긴다: 임시 ↔ 검토 ↔ 포스트. 임시에서 포스트로 바로 가지 않는다.
- 행마다 버튼이 있고, 체크한 여러 건을 위쪽 버튼으로 한꺼번에 옮길 수도 있다.
- 옮겨도 상태값은 지우지 않는다. 되돌아오면 하던 상태 그대로다.
- **발행 완료한 포스트는 검토로 되돌리지 않는다.** 발행을 미발행으로 바꾸면 다시 옮길 수 있다.
- 목록에서 '발행 완료'를 누르면 발행일이 비어 있을 때 오늘 날짜가 들어간다. 발행 주소는 글을 열어 적는다.

## 글 보기 (`/blog/writing/<번호>/`)

목록에서 행을 누르면 열린다. **여기서 작업을 끝내고 그대로 복사해 블로그에 붙여넣는 곳**이라, 붙여넣은 뒤 다시 손댈 일이 없게 만든다.

- 블로그에 올라간 모습 그대로: 제목 · 날짜 · 본문 · `#태그`. PC / 모바일 폭으로 바꿔 볼 수 있다 (고른 폭은 브라우저에 기억).
- 위쪽 복사 버튼:
  - **본문 (서식 그대로)**: 네이버 스마트에디터, 티스토리 기본 모드에 붙여넣기. 소제목·굵게·목록·표·인용·사진 자리 상자 서식이 따라간다.
  - **본문 HTML**: 티스토리 HTML 모드에 붙여넣기.
  - **제목**, **태그**(쉼표로 구분), 요약(정보 칸의 복사 버튼).
- 정보 칸: 화면별 상태(여기서 바로 바꿈), 요약, 사진·그림 자리 개수.
- 글자 수: 사진·그림 자리 상자를 뺀 본문 글자 수, 공백 제외 글자 수.
- 위·아래 화살표와 맨 아래 링크로 같은 화면 목록의 이웃 글로 넘어간다 (목록 순서 그대로).
- 수정 → 저장하면 다시 글 보기로 돌아온다.

### 본문 쓰는 법 (`apps/writing/render.py`)

| 쓰는 법 | 보이는 것 |
|---|---|
| 빈 줄 / 줄바꿈 한 번 | 문단 나누기 / 그대로 줄바꿈 |
| `## 소제목`, `### 작은 소제목` | 소제목 |
| `**굵게**`, `- 목록`, `1. 번호`, `> 인용`, `---` | 그대로 |
| `\| 칸 \| 칸 \|` 표 | 테두리 있는 표 |
| `[사진] 설명` 또는 `📷 설명` | 빨간 점선 상자: 내 사진 올릴 자리 |
| `[그림] 파일명` 또는 `![설명](그림1.png)` | 파란 점선 상자: 준비한 그림 올릴 자리 |
| `![설명](https://주소)` | 실제 이미지 |
| `[캡션] 문장` 또는 이미지 바로 다음 줄의 `*문장*` | 가운데 회색 캡션 |
| `<!-- 메모 -->` | 안 보이고 복사에도 안 들어감 |

- 붙여넣기용 HTML 은 꾸밈을 **인라인 style** 로 넣는다. 블로그 에디터가 붙여넣을 때 외부 CSS 를 버리기 때문이다. 형식은 시험 원고의 `붙여넣기.html` 과 같다 (`콘텐츠/블로그_카페/포스팅자동화/원고/`).
- 시험 원고 `원고.md` 의 본문(`<!-- 본문 시작 -->` ~ `<!-- 본문 끝 -->`)을 그대로 넣으면 같은 모습으로 나온다.
