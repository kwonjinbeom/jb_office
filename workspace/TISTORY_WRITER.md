# 티스토리 글쓰기 도우미

> 2026-10-15 요구 정정: 아래는 기존 구현 설명이다. 사용자가 원하는 것은 AI가 이미지·멘트·말투까지 갖춘 거의 완성된 포스팅을 만들고 사용자는 소폭 수정하는 자동화다. 현재 구현이 이 목표를 충족한 것은 아니다. 후속 작업은 [`포스팅자동화/00_요구사항.md`](../콘텐츠/블로그_카페/포스팅자동화/00_요구사항.md)를 기준으로 진행한다.

메뉴: **블로그·카페 → 티스토리 글쓰기** (`/blog/writing/`). 내 원고·템플릿·작성 설정으로 구성한다.

## 글 한 편의 흐름

1. **새 원고:** 제목·글 형식·작성 규칙·폴더를 선택.
2. **기획·자료:** 독자의 질문, 핵심 답, 실제 경험, 원문·확인일·메모를 기록.
3. **원고 작성:** 구성 만들기 또는 AI 초안. 소제목·강조·목록·인용·링크·표·이미지 자리 편집.
4. **검수:** 미리보기, 미작성 표시·문단·자료 확인일·제휴 표시 자동 점검, 사람이 확인하는 항목 5개.
5. **티스토리에 옮기기:** 제목·태그 별도 복사. 기본모드는 서식 있는 본문, HTML모드는 HTML 코드. 이미지와 최종 표시를 티스토리에서 확인.
6. **게시 후:** URL·날짜 기록. 기존 블로그·카페 콘텐츠의 게시 기록과 연결.

블로그·카페의 기존 글에서도 **글쓰기 도우미로 열기**로 시작할 수 있다. 같은 Content를 사용하므로 제목·본문을 두 곳에서 따로 관리하지 않는다.

## 템플릿과 작성 규칙

- 기본 8종: 해결·사용법 / 비교 / 경험·리뷰 / 큐레이션 / 소식·해설 / 취향·칼럼 / FAQ / 체크리스트.
- 기본 틀을 복사하거나 직접 내 템플릿을 저장한다.
- 치환: `{{answer}}`, `{{question}}`, `{{experience}}`, `{{closing}}`, `{{title}}`, `{{keyword}}`.
- 미작성: `[[작성할 내용]]`. 검수에서 남은 표시를 확인한다.
- 작성 규칙: 채널 주소, 독자, 말투, 추가 기준, 마무리, 제휴 표시, 목표 분량. 목표 분량은 작성 참고이며 검색 순위 기준이 아니다.

## 저장·복구

- 입력을 멈추면 자동 저장. 직접 저장·Ctrl+S도 지원.
- revision과 공유 Content의 해시를 확인해 다른 화면에서 바꾼 원고를 덮지 않는다.
- 저장 실패 시 탭별 브라우저 복구 자료를 보관한다. 다른 탭의 저장이 해당 자료를 지우지 않는다.
- **현재 편집 백업**은 서버 저장 없이 현재 입력을 JSON으로 내려받는다. 네트워크 오류·변경 충돌 때도 사용 가능.
- 최근 30개 이전 버전. 자동 저장은 2분 간격으로 이전 상태를 보관하고 직접 저장·구성·AI·복구 전에는 별도 보관.
- 구성·AI·복구 후에도 입력 내용과 자료가 한 원고에 유지된다.
- JSON 백업을 새 원고로 가져올 수 있다. 게시 상태·URL은 초기화한다. 삭제된 작성 규칙·템플릿은 기본값으로 대체한다.
- 게시 완료 원고의 내용을 수정하면 검토 상태로 돌아간다. 실제 게시 업데이트 후 상태를 다시 표시한다.

## AI 초안

- 작성 설정에서 OpenAI API 키·모델을 저장. 기본 모델 `gpt-4.1-mini`.
- API 키는 비밀번호 입력으로 받고 화면·원고·백업에 반환하지 않는다.
- 서버 환경의 `OPENAI_API_KEY`, `WRITING_AI_MODEL`도 사용할 수 있다. 화면에서 저장한 값이 우선한다.
- 연결 설정이 없으면 구성 만들기·AI 요청문 복사·외부 AI 원고 붙여넣기로 진행.
- 초안 생성에는 질문·핵심 답을 먼저 입력. 제공된 자료·경험·규칙으로 요청하고 미확인 부분은 작성 표시로 남기도록 한다.
- 생성 시 편집 입력을 잠시 잠그며, 다른 창에서 원고가 바뀌면 결과로 덮지 않는다. API 오류·시간 초과에도 원고를 유지한다.
- API 계정 사용량에 따라 과금. 실제 계정 키와 서비스 접근 권한은 사용자가 설정해야 한다.
- 이번 개발 검증에서는 API 응답을 모의 처리했고 실제 유료 API를 호출하지 않았다.

## 구조와 서버 반영

- `apps/writing/`: 모델·템플릿 카탈로그·검수·HTML 변환·AI 연결·뷰·테스트.
- `Draft.content`: 기존 `content.Content`와 OneToOne. 추가 메타·자료·확인표·버전은 writing 앱에 저장.
- HTML은 허용된 본문 요소·링크·이미지만 내보낸다. 스크립트·이벤트 속성·실행형 URL은 제거한다. 미리보기는 sandbox iframe.
- 새 의존성 없음. 기존 Django·Markdown과 표준 라이브러리 사용.
- **서버 migrate 필요:** writing 초기 migration. 기존 웹훅·서버 코드 갱신의 자동 migration 경로로 처리한다.
- 실제 티스토리에 글을 등록하는 자동 게시 기능은 포함하지 않는다. 작성·검수·게시용 복사를 제공한다.
