# 콘텐츠와 논의 메뉴

Claude UI `3775b28`의 표·폼·아이콘을 사용한다. 기존 메뉴와 데이터는 유지한다.

## 사용

| 메뉴 | 시작 | 기록 |
|---|---|---|
| 블로그·카페 | 채널·카테고리 폴더 추가 | 소재·템플릿·글, 게시처별 버전·URL·반응 |
| 영상 콘텐츠 | 시리즈·세부 주제 폴더 추가 | 소재·기획·대본·자료, 플랫폼별 버전 |
| 논의 현황 | 메뉴·상위 주제 선택 | 현재 핵심 140자, 다음 행동 80자, 상태·대화량·상대 |

- 폴더와 논의 주제는 계속 세분화할 수 있다. 상위 분류 필터는 하위 내용도 포함한다.
- 폴더 설정에 독자·목적·말투·작성 규칙을 둔다.
- 템플릿 상세에서 **이 템플릿으로 작성**을 누르면 새 원고의 구성·본문·자료에 복사된다. 원본은 유지한다.
- 논의 표에서 핵심·다음·상태를 바로 저장한다. 상대·대화량은 수정 화면에서 설정한다.
- 요약이 달라졌을 때만 이력을 남긴다. 상세 화면의 접힌 이력에서 확인한다.
- 대화 전문이나 AI 대화 자동 수집은 없다. Codex·Claude와 대화한 후 핵심만 기록한다.
- 내용이 있는 폴더·상위 주제는 바로 삭제할 수 없다. 먼저 하위 내용을 옮긴다.
- 콘텐츠 상세에서 Markdown 파일을 내려받을 수 있다.
- Git 작업 폴더는 `콘텐츠/`에 있다. 서버 DB와 자동 동기화되지는 않는다.

## 서버 반영

**서버 migrate 필요 — 기존 서버 반영 기능에서 자동 실행한다.** 새 `content`, `discussions` 앱의 초기 migration을 추가했다.

GitHub push 웹훅과 화면의 서버 코드 갱신은 같은 `pull_and_reload()`를 사용한다. 최신 코드를 받은 뒤 서버 가상환경 Python으로 `migrate --noinput` → `collectstatic` → 재시작을 수행한다. 이 두 앱도 자동 적용 대상이므로 별도 수동 migration 명령은 필요 없다.

웹훅이 등록되어 있으면 main push에 자동 반영된다. 웹훅을 사용하지 않을 때는 기존 서버 코드 갱신 기능이 같은 순서로 처리한다. 실행 결과·오류는 기존 배포 상태와 갱신 메시지에 기록된다.

추가 패키지는 없다. 2026-10-14 사용자가 최신 main 병합과 푸시를 승인했다. 서버 배포는 사용자가 진행한다.
