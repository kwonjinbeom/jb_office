# 콘텐츠 제작 공간과 논의 현황 추가

기존에는 조사 후보와 실행할 아이디어를 관리했다. 이제 글·영상 제작을 별도 메뉴에서 진행하고, AI와 논의한 세부 주제는 핵심만 표로 관리한다.

- 블로그·카페: 계층 폴더, 독자·말투·작성 규칙, 소재·템플릿·글, 템플릿 복사, 게시처별 버전·기록.
- 영상 콘텐츠: 같은 제작 구조에 대본·장면·자료와 플랫폼별 변형을 저장.
- 논의 현황: 메뉴 → 상위 주제 → 하위 주제. 핵심 한 문장·다음 행동 하나를 표에서 수정. 대화량·상대와 접힌 요약 이력.
- 기존 메뉴·데이터 유지. Claude UI `3775b28`의 표·폼·아이콘 사용.
- `콘텐츠/`에 Git 공유용 규칙·템플릿·현재 합의 추가. 웹 DB와 자동 동기화되지 않으며 콘텐츠는 Markdown 다운로드 가능.

- Django 전체 테스트 20개 통과: 계층 필터, 순환 방지, 공간 분리, 템플릿 복사, 게시 기록, 요약 이력, 글자 수 제한, CSRF·로그인, 다운로드·안전한 복귀 경로.

- migration은 `/tmp`의 임시 DB에서만 적용. 화면 샘플도 임시 DB 자료.
